## 从旧版升级

升级前请备份数据目录（默认 `~/.dsh-uncensored`）和重要工作区。

- **从 `2026.11.24.3` 升级**，在应用菜单中点「检查更新」。若下载或安装失败，可退出 DSHU，从本页下载对应安装包，手动覆盖安装。
- **从首发版 `2026.11.23.0` 升级**，请退出 DSHU，从本页下载对应系统和架构的安装包，覆盖安装一次。Linux 沿用原来的 DEB 或 RPM 格式。

手动下载后，可展开本页「校验下载（SHA-256）」核对安装包。升级后，打开「关于」，在左侧核对 DSHU 版本，再继续原工作区的对话。

## 四种模式随包交付

- 本版把上一正式版的专项能力并回新内核：**缺省、写作、网安、逆向**四种模式全部随安装包提供。写作模式保留七份写作手册与五份参考资料，网安与逆向模式各自带上调查、取证、样本分析与现场手册。
- **破甲核心改用社区维护版 `dsh-purge Community v1.7.20`**，随包挂载为提示词段；另加可选尾部强化段，默认关闭，四个片段由 `armor-core.lock.json` 钉住摘要。
- **REA 6.9.0 随包**：逆向模式下模型可以直接调用 REA 工具，贴入 ELF、PE 或单架构 Mach-O 文件头即可询问格式与 CPU 架构；Ghidra/Java、IDA 或 Hopper 按需另行配置。
- 新增卫兵插件 `refusal-retry`：一轮的最终回答若以拒绝开头且没有发起工具调用，就在同一轮内用下一档臂续写；每轮最多 1 档推进、2 次重试，会话上限 6 次。
- 关于页的「随包组件与许可」按实际载荷展示组件名称、版本、来源提交、提交时间与许可，区分随包提供和需要用户另行配置的部分。

## 对话与计费

- 主对话底部统一显示费用估算与额度状态。旁问中的模型调用和输入预测归入所属主对话，清理旁问后仍能查到已经产生的费用。重新打开会话或切换旁问时，每次调用只算一次。只要还有请求缺少用量或费率，底栏和明细都会在已知金额前显示 ≥。
- 旁问支持带图续聊。折叠侧栏后，可以从入口看到旁问是否还在运行、是否有未读回答。主对话需要某个旁问结论时，可以直接让它读取。随问可在主任务运行时查看进展，回答独立保存。
- 修复了旁问同时打开时重复请求、同一份草稿重复触发输入预测，以及切换工作区时文件夹短暂显示上一对话模式色的问题。

## 记忆、余额与外观

- 跨对话记忆成为常规功能，默认关闭。在「设置 → 通用」开启后，可以查看、修订、停用或删除记录，并按工作区和模式使用。自动提炼有独立开关，默认也关闭。例如，在一个写作对话中保存小说设定后，同一工作区的新写作对话可以沿用它。修订会作用于之后的检索，停用记录会将它移出检索。关闭总开关仍会保留已保存的记录。
- 「设置 → 额度」可以拖动余额曲线下方的左右把手，查看留存期内任意一段原始采样。侧栏曲线可以隐藏，短、中、长三档分别显示最近 24 小时、7 天和 30 天，默认中档。新配置默认自动清理超过 30 天的采样，升级保留已经保存的清理策略。修复了采样期间切换账号可能误清另一账号历史的问题。
- 重新设计额度和模式设置。关于页在桌面左侧、手机顶部铺满主题渐变，品牌区显示 DSHU 产品版本，详细信息区显示 DSH 内核、源码与许可。日出日落外观支持手选城市。侧栏移除了插件「更多」按钮，插件仍可在设置中管理。

## 内核兼容与桌面升级

- 新内核采用 DeepSeek Harness `0.2.3-alpha.2`。修复了旧配置中的同名依赖遮蔽桌面自带服务的问题，也能重新打开、续写含旧版输入建议记录的对话。[#20](https://github.com/Water-Run/deepseek-harness-uncensored/issues/20)
- 修复了含保护审计记录的旧对话升级后无法打开的问题。普通和压缩会话均可继续，原来的允许、拒绝和取消记录会保留，包括旧版写入的指纹及目标名称。
- 升级后可继续使用原有的文风卡与设定集，保留原先的勾选和修订记录。
- Windows 安装器可以识别以 `.0` 结尾的 DSHU 日期版本，支持从首发版静默覆盖升级，以及同版重装修复。[#24](https://github.com/Water-Run/deepseek-harness-uncensored/issues/24)
- 遇到点名 MCP 工具的 HTTP 400，可展开原始错误下的恢复指引。若工具名与出错前的请求记录一致，可按指引停用对应服务并回到原对话重发。名称对不上或记录尚未加载时，界面会提示先核对工具来源。已有消息、调用结果和其他仍启用的工具声明都会保留。该设置会影响使用此服务的其他对话。[#25](https://github.com/Water-Run/deepseek-harness-uncensored/issues/25)
- macOS 应用内更新准备失败后，可以直接重试。应用会重新校验缓存的 DMG，损坏时重新下载，完整的安装包可直接复用。
- 修复工具重连后仅因 JSON 字段顺序变化就重建声明的问题。支持在消息中记录工具启停的 API 可以沿用原有声明和启停记录。[#23](https://github.com/Water-Run/deepseek-harness-uncensored/issues/23)
- 联网抓取增加地址钉扎：解析结果按公网/保留地址分级，重定向与代理隧道逐跳复核，避免把抓取落到本机或内网地址。
- 桌面安装包为五个，覆盖 Windows x64、Apple 芯片 Mac、Linux x64（DEB 和 RPM）及 Linux ARM64（DEB）。仓库首页可直接播放带中文配音和字幕的功能演示。

## 已知问题

- 网安模式的**代理设置面板与真实目标保护**尚未随本版：按域名/主机/数据库的保护规则、审计联动与流量查看器仍在移植中。模式入口、敏感确认与案件资料可用，出口代理按内置配置工作。
- 设置中的「内置插件」分区（`client-ui-settings-plugins`）尚未随包；插件清单仍可在「插件管理 → 插件列表」查看。
- PTC 的 Python 运行时与个性化推荐未随本版。
- 部分 Windows 11 用户报告应用静置时卡死。已修复旁问和输入预测中的重复请求。在保留旧会话的安装测试中未复现整机卡死，原报告的根因仍待确认。[#26](https://github.com/Water-Run/deepseek-harness-uncensored/issues/26)
- 第三方 API 的实际缓存命中量以服务商返回的数据为准。报告所用服务的缓存读写量仍待核实。[#23](https://github.com/Water-Run/deepseek-harness-uncensored/issues/23)
