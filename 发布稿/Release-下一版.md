DSHU 2026.11.27.0

- 四种模式升级至 DeepSeek Harness `0.2.3-alpha.2`，修复部分旧工作区无法打开和 Windows 安装器拒绝升级的问题。
- 跨对话记忆转为正式功能，默认关闭。旁问支持带图续聊，费用计入主对话。
- 更新关于页、额度和模式设置。余额曲线可拖动选择时段，侧栏可隐藏或切换范围，新配置默认保留 30 天采样。

升级前请备份数据。`2026.11.24.3` 可在应用菜单检查更新，首发版 `2026.11.23.0` 需下载对应安装包覆盖安装。

本版暂缺网安代理面板与真实目标保护、「内置插件」分区、PTC 的 Python 运行时和个性化推荐。另见 [#23 第三方 API 缓存](https://github.com/Water-Run/deepseek-harness-uncensored/issues/23)、[#26 Windows 11 静置卡死](https://github.com/Water-Run/deepseek-harness-uncensored/issues/26)。
