## 从旧版升级

使用 `2026.11.23.0` 或 `2026.11.24.3` 的用户，请先退出 DSHU，备份数据目录（默认 `~/.dsh-uncensored`）和重要工作区，然后从本页下载对应系统及架构的安装包，覆盖安装一次。Linux 请用系统的软件包管理器安装，沿用原来的 DEB 或 RPM 格式。启动后可在「关于」左侧核对 DSHU 版本，再打开原工作区继续对话。

## 对话与计费

- 主对话底部统一显示费用估算与额度状态。旁问中的模型调用和输入预测归入所属主对话，清理旁问后仍能查到已经产生的费用。重新打开会话或切换旁问时，每次调用只算一次。只要还有请求缺少用量或费率，底栏和明细都会在已知金额前显示 ≥。
- 旁问支持带图续聊。折叠侧栏后，可以从入口看到旁问是否还在运行、是否有未读回答。主对话需要某个旁问结论时，可以直接让它读取。随问可在主任务运行时查看进展，回答独立保存。
- 修复了旁问同时打开时重复请求、同一份草稿重复触发输入预测，以及切换工作区时文件夹短暂显示上一对话模式色的问题。

## 记忆、余额与外观

- 跨对话记忆成为常规功能，默认关闭。在「设置 → 通用」开启后，可以查看、修订、停用或删除记录，并按工作区和模式使用。自动提炼有独立开关，默认也关闭。例如，在一个写作对话中保存小说设定后，同一工作区的新写作对话可以沿用它。修订会作用于之后的检索，停用记录会将它移出检索。关闭总开关仍会保留已保存的记录。
- 「设置 → 额度」可以拖动余额曲线下方的左右把手，查看留存期内任意一段原始采样。侧栏曲线可以隐藏，短、中、长三档分别显示最近 24 小时、7 天和 30 天，默认中档。新配置默认自动清理超过 30 天的采样，升级保留已经保存的清理策略。
- 重新设计额度和模式设置。关于页在桌面左侧、手机顶部铺满主题渐变，品牌区显示 DSHU 产品版本，详细信息区显示 DSH 内核、源码与许可。日出日落外观支持手选城市。侧栏移除了插件「更多」按钮，插件仍可在设置中管理。

## 内核兼容与桌面升级

- 新内核采用 DeepSeek Harness `0.2.3-alpha.2`。修复了旧配置中的同名依赖遮蔽桌面自带服务的问题，也能重新打开、续写含旧版输入建议记录的对话。[#20](https://github.com/Water-Run/deepseek-harness-uncensored/issues/20)
- 写作模式保留七份写作手册和五份参考资料。升级后可继续使用原有的文风卡与设定集，保留原先的勾选和修订记录。
- Windows 安装器可以识别以 `.0` 结尾的 DSHU 日期版本，支持从首发版静默覆盖升级，以及同版重装修复。[#24](https://github.com/Water-Run/deepseek-harness-uncensored/issues/24)
- 修复部分 MCP 工具声明导致原会话持续返回 HTTP 400 的问题。服务商点名拒绝某个工具后，可以在原对话继续，其他工具的声明会保留。[#25](https://github.com/Water-Run/deepseek-harness-uncensored/issues/25)
- 桌面安装包精简为五个，覆盖 Windows x64、Apple 芯片 Mac、Linux x64（DEB 和 RPM）及 Linux ARM64（DEB）。仓库首页可直接播放带中文配音和字幕的功能演示。

## 已知问题

- 部分 Windows 11 用户报告应用静置时卡死。已修复旁问和输入预测中的重复请求。在保留旧会话的安装测试中未复现整机卡死，原报告的根因仍待确认。[#26](https://github.com/Water-Run/deepseek-harness-uncensored/issues/26)
- 第三方 API 的缓存命中取决于服务商。针对 HTTP 400 的修复保留了未被拒绝的工具声明。目前尚无报告所用服务商的缓存用量对照。[#23](https://github.com/Water-Run/deepseek-harness-uncensored/issues/23)
