# Windows 安装器版本检查

[English](guide.md) | 中文

## 变更

Windows 安装器在替换程序前，将独立的 Desktop 产品版本与当前用户已登记的 DSHU 版本比较。较低版本会被拒绝。已登记的程序存在但版本缺失，或版本无效时，也会停止安装。静默安装返回退出码 2。同版修复和升级均可继续。版本顺序遵循 SemVer，包括预发布字段的数字比较。

## 迁移

1. 升级或修复时，使用相同或更新 Desktop 产品版本的安装器。
2. 主动回退时，先备份 DSHU 数据目录，再卸载当前应用。普通卸载保留用户数据。打开旧版本前，确认它支持现有数据格式。
3. 在关于页和 Windows 卸载项中核对结果版本。此检查加入前构建的安装器保留原有行为。
