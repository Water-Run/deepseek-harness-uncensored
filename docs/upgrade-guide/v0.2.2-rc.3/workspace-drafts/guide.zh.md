# 工作区草稿隔离

[English](guide.md) | 中文

## 变更

空白对话在同一工作区目录内保留未发送的新对话草稿；未绑定工作区的对话使用独立槽位。打开其他工作区且对应会话没有草稿时，输入框保持空白。浏览器中的旧键 `dsh.conversation.new` 不再读取；已有会话草稿的键和值保留。

## 迁移

1. 更新前请复制仍未发送的文字，尤其是未绑定工作区的草稿。各会话自身的草稿保留，可重新打开原工作区恢复。旧浏览器条目 `dsh.conversation.new` 留存供恢复，不会猜测它属于哪个工作区。
2. 需要在其他工作区使用相同内容时，请明确复制文本。
3. 切换到其他工作区的空白对话，确认输入为空；返回来源时，确认文本和引用均恢复。
