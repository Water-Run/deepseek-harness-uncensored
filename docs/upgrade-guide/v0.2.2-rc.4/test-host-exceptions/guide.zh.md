# 精确主机名测试例外

[English](guide.md) | 中文

## 变更

启用可选目标保护后，早期的主机名测试规则也可能匹配推断出的名称或共享地址。现在，规则将请求的主机名与主选择器及所有者配置的主机名别名精确匹配。IP 选择器覆盖匹配的固定连接地址。生产规则仍检查每个已验证的名称和地址。

## 迁移

1. 在[目标保护面板](../../../../packages/client/ui-security-proxy/README.zh.md)打开受影响的测试规则。对你拥有并需要测试的其他主机名，在 `aliases` 中添加主机选择器，设置相应端口与适用的数据库限定，然后点击 **保存规则**。
2. 用配置好的主机名重试允许的请求。确认生产规则仍然优先，并核对其他主机名仍接受常规地区检查。
