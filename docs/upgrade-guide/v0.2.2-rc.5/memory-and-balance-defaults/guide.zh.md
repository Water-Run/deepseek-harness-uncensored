# 记忆与余额偏好

[English](guide.md) | 中文

## 变更

对话使用已保存的事实或记忆工具前，需要打开跨对话记忆。管理页仍可查看已有记录。采用默认设置时，下次保存新余额采样会清理 30 天以前的记录。已明确设置的清理方式优先生效。

## 迁移

1. 需要继续检索已保存的事实时，在 **设置 → 通用** 中打开**跨对话记忆**。自动提炼可单独开启。
2. 需要保留更早的余额采样时，在启动升级后的 Host 前，将余额插件的 `autoCleanup` 设为 `off`。打开 **设置 → 额度 → 采样设置** 确认清理方式与保留天数。
