## 会话与工作区

| 功能 | 入口和行为 |
| --- | --- |
| 新建会话与选择工作区 | 从侧栏「新会话」进入。可选已有工作区、添加目录或选择「不在工作区工作」。工作区选择列表支持按名称与路径搜索。 |
| 搜索与筛选 | 从工作区标题旁的搜索和筛选入口查找会话。列表可隐藏归档、显示全部或只显示归档。快捷键以界面提示为准。 |
| 重命名与复制 ID | 右键会话行或打开其省略号菜单。可指定标题，并复制该会话的完整 ID 供定位。 |
| 置顶与拖动 | 置顶区先显示，普通会话可在自己的区域拖动排序。跨置顶分区放下时会提示规则。手动和最近更新是不同排序方式。 |
| 归档与撤销 | 从会话菜单选择「归档」。有任务在运行时会要求确认停止。可通过归档筛选找回并取消归档。 |
| **删除对话** | 从会话菜单选择「删除对话」，确认「停止并删除」。会先停止相关工作，再永久清理该会话及其所属旁问、随问和子会话。独立分叉和工作区文件保留。失败时按弹窗提示重试。 |
| 从会话或消息分叉 | 会话菜单以最近一次已完成的轮次为起点。消息下的分叉从所选位置创建独立会话。若创建时已切换页面，可从提示打开新分支。 |
| 移除工作区 | 从工作区菜单操作。移除分组后，其会话留在「未分组」。只想收起列表时点组名旁的折叠按钮。 |
| 进行中的任务 | 侧栏状态区区分等待审批、计划待审与等待回答。桌面可从「进行中的会话」定位活跃任务。定时任务见[自动化任务指南](schedule.zh.md)。 |

删除前确认选中的标题及关联范围。希望从列表隐藏以后再打开时，可使用归档。跨对话记忆在自己的管理入口编辑。[会话删除和分叉的行为](../../../packages/api/session-controller/README.zh.md)

<a id="composer"></a>
## 旁问、随问与输入区

| 功能 | 入口和行为 |
| --- | --- |
| 打开旁问 | 使用会话顶部的旁问按钮、右侧开始页「旁问」，或发送 `/side`。输入 `/side 问题` 可同时打开并发送。 |
| 旁问参考范围 | 每次提问参考主线已完成的新进展，自己的往来独立保存。主线可根据需要查看对应旁问。 |
| 旁问附件 | 在旁问输入框添加图片。能否分析图像取决于当前模型是否支持图像输入。 |
| 清理旁问 | 在旁问中发送 `/clear`。关闭旁问默认保留历史，可在通用设置开启关闭时清理。 |
| 随问 | 在主输入框发送 `/btw 问题`。简短回应显示在原会话内，侧栏不会新增普通会话。 |
| 引用与附件 | 输入 `/` 查看可用命令，输入 `@` 引用文件或会话。用输入框的添加按钮附加文件。 |
| 忙碌时发送 | 运行中仍可输入。去通用设置调整繁忙时的发送行为，或在当前会话使用停止按钮。 |
| 输入预测 | 默认开启。主线、旁问和随问分别预测草稿，按 Tab 填入，由你决定是否发送。预测使用模型并可能计费。 |
| 右侧工具区 | 从右侧开始页打开工作区文件、终端或旁问。更多工具显示已装配且可用的入口。快捷键以面板显示为准。 |

## 余额、费用与限额

| 功能 | 入口和行为 |
| --- | --- |
| 账户余额 | 打开「设置 → 额度」或侧栏余额卡片。支持实时余额与本机历史，默认每 15 秒采样，设置最短可到 3 秒，也可立即刷新。 |
| 查看时间点 | 把指针移到图上，轻触或聚焦后用方向键，可读取采样日期、时间及具体金额。余额上升用竖虚线，长时间平稳区间用横虚线缩短。 |
| 对话费用 | 点击输入区下方的金额，展开当前会话的估算及曲线。账户余额和对话费用分开查看。 |
| 限额窗口 | 额度设置的六档窗口各自启停、设置金额及重置。默认全关，先显示 5 小时与 7 天，其余可展开。 |
| 查看限额用量 | 点击底栏限额状态，展开各启用窗口的用量进度。进入额度设置后可调整、关闭或重置。 |
| 暂停与恢复 | 达到限额时横幅显示原因、可用的恢复时间与快捷入口。自动恢复默认关闭，开启后额度恢复时可继续暂停的任务。 |

本地统计重置只影响限额计算。服务商计费、充值、赠金和余额变化分别按各自记录核对。[费用与限额指南](dshu.zh.md#spending)

<a id="modes-tools"></a>
## 模式、资料、工具与记忆

| 功能 | 入口和行为 |
| --- | --- |
| 模式选择与指示 | 新会话首次发送前选缺省、网安、逆向或写作。已有会话默认锁定，可在设置里临时允许空闲会话切换。顶部指示与侧栏色条显示所用模式。 |
| 模式说明与配置 | 「设置 → 模式」可分别查看说明、使用示例和配置。写作只把已选的参考文风和设定用于后续请求。 |
| 可选保护与审计 | 网安配置可查看独立代理开关、提醒与可选执行保护覆盖。保护默认关闭，已启用的覆盖范围和脱敏审计可在设置中查阅。 |
| 内置 REA 与插件 | 在逆向配置检查 REA 连接以及各外部引擎状态。插件在设置中查看、搜索与管理。可选引擎的配置与平台要求见[工具接入](dshu.zh.md#tools)。 |
| 跨会话记忆 | 在记忆管理中查询、编辑、禁用或删除记录，按范围查看。自动提炼默认关闭。 |

<a id="settings-data"></a>
## 设置、数据与恢复

| 功能 | 入口和行为 |
| --- | --- |
| 工作步骤与用量 | 通用设置可调整步骤展开、收起时机和用量级别。新配置默认全展开、下次新消息时收起、详细用量。 |
| 官方 API 日志选项 | 通用设置中的 Session Log 上传只适用于官方模型 API。新配置默认开启，已有设置优先。 |
| 外观 | 选择浅色、深色、跟随系统或日出日落。各模式使用自己的主题色提示当前任务。 |
| 关于与版本 | 「关于」显示 WaterRun、DSHU 与 DSH 版本、编译信息、源码和 REA 来源。遇到同日多个构建时可同时核对版本及提交。 |
| 备份与卸载 | DSHU 默认使用 `~/.dsh-uncensored` 保存独立数据。更新前保留备份，卸载时按需选择资料保留或清理。[数据、更新与恢复](dshu.zh.md#data) |

需要首次配置时回到[使用手册](dshu.zh.md)。发布和候选验收见[首发打包交接](../../../.agents/requirements/windows-x64-first-release.md)。
