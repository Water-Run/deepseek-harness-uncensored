## 会话与工作区

| 功能 | 入口和行为 |
| --- | --- |
| 新建会话与选择工作区 | 点击侧栏的「新会话」。可以选择已有工作区、添加目录，或选择「不在工作区工作」；工作区列表支持按名称和路径搜索。 |
| 搜索与筛选 | 使用工作区标题旁的搜索和筛选按钮。列表可以隐藏归档、显示全部或只显示归档会话。快捷键以界面提示为准。 |
| 重命名与复制 ID | 右键点击会话行，或打开行尾的省略号菜单。可以修改标题，也可以复制会话的完整 ID 以便定位。 |
| 置顶与拖动 | 置顶会话排在最前，普通会话可以在各自区域内拖动排序；拖过置顶分界时会提示规则。手动排序和按最近更新排序是两种独立方式。 |
| 归档与撤销 | 在会话菜单中选择「归档」。如有任务正在运行，会先确认是否停止。之后可以通过归档筛选找回并取消归档。 |
| **删除对话** | 在会话菜单中选择「删除对话」，再确认「停止并删除」。系统会先停止相关工作，再永久删除该会话及其旁问、随问和子会话；独立的分叉和工作区文件不受影响。失败时按弹窗提示重试。 |
| 从会话或消息分叉 | 从会话菜单分叉时，以最近一次完成的轮次为起点；从消息下方分叉时，以所选位置为起点创建独立会话。创建期间切换了页面的话，可以从提示中打开新分支。 |
| 移除工作区 | 在工作区菜单中操作。移除后，该组的会话会移到「未分组」。如果只想收起列表，点击组名旁的折叠按钮即可。 |
| 进行中的任务 | 侧栏状态区分别标出等待审批、计划待审和等待回答的会话。桌面版可以从「进行中的会话」定位正在运行的任务。定时任务见[自动化任务指南](schedule.zh.md)。 |

删除前请确认选中的标题和关联范围。如果只是想暂时从列表中隐藏、以后再打开，请使用归档。跨对话记忆需要在记忆管理中单独编辑。[会话删除和分叉的行为](../../../packages/api/session-controller/README.zh.md)

## 旁问、随问与输入区

| 功能 | 入口和行为 |
| --- | --- |
| 打开旁问 | 点击会话顶部的旁问按钮或右侧开始页的「旁问」，也可以发送 `/side`。输入 `/side 问题` 会打开旁问并直接发送。 |
| 旁问参考范围 | 每次提问都会参考主线已完成的新进展，旁问自己的对话独立保存。主线可以按需查看对应的旁问。 |
| 旁问附件 | 在旁问输入框中添加图片。能否识别图像，取决于当前模型是否支持图像输入。 |
| 清理旁问 | 在旁问中发送 `/clear`。关闭旁问默认保留历史，也可以在通用设置中改为关闭时自动清理。 |
| 随问 | 在主输入框发送 `/btw 问题`。简短回答显示在当前会话中，侧栏不会新增会话。 |
| 引用与附件 | 输入 `/` 查看可用命令，输入 `@` 引用文件或会话。点击输入框的添加按钮附加文件。 |
| 忙碌时发送 | 任务运行时仍可输入。可以在通用设置中调整忙碌时的发送方式，或使用当前会话的停止按钮。 |
| 输入预测 | 默认开启。主线、旁问和随问分别根据草稿给出建议，按 Tab 填入，是否发送由你决定。预测会调用模型，可能产生费用。 |
| 右侧工具区 | 从右侧开始页打开工作区文件、终端或旁问；「更多工具」列出已装配且可用的入口。快捷键以面板显示为准。 |

## 余额、费用与限额

| 功能 | 入口和行为 |
| --- | --- |
| 账户余额 | 打开「设置 → 额度」或点击侧栏的余额卡片。可以查看实时余额和本机历史，默认每 15 秒采样一次，最短可设为 3 秒，也可以立即刷新。 |
| 查看时间点 | 把指针移到曲线上、轻触，或聚焦后使用方向键，可以读取采样的日期、时间和金额。余额上升以竖向虚线标出，长时间平稳的区间以横向虚线压缩。 |
| 对话费用 | 点击输入区下方的金额，展开当前会话的费用估算和曲线。账户余额与对话费用分开显示。 |
| 限额窗口 | 额度设置中的六档窗口可以分别启停、设定金额和重置。默认全部关闭，5 小时与 7 天显示在前，其余可以展开。 |
| 查看限额用量 | 点击底栏的限额状态，查看各已启用窗口的用量进度；进入额度设置后可以调整、关闭或重置。 |
| 暂停与恢复 | 达到限额时，横幅显示原因、预计恢复时间和快捷操作。自动恢复默认关闭；开启后，额度恢复时会继续被暂停的任务。 |

重置本地统计只影响限额计算。提供方的计费、充值、赠金和余额变化，请分别按各自的记录核对。[费用与限额指南](dshu.zh.md#spending)

## 模式、资料、工具与记忆

| 功能 | 入口和行为 |
| --- | --- |
| 模式选择与指示 | 新会话在第一次发送前选择缺省、网安、逆向或写作。已有会话默认锁定模式，可以在设置中临时允许空闲会话切换。会话顶部的指示和侧栏色条会标出当前模式。 |
| 模式说明与配置 | 在「设置 → 模式」中可以分别查看各模式的说明、使用示例和配置。写作模式只把已选的参考文风和设定用于后续请求。 |
| 可选保护与审计 | 网安配置中可以管理独立代理开关、未启用提醒和可选的执行保护。保护默认关闭；启用后，覆盖范围和脱敏审计记录可在设置中查阅。 |
| 内置 REA 与插件 | 在逆向配置中检查 REA 连接和各外部引擎的状态。插件在设置中查看、搜索和管理。可选引擎的配置和平台要求见[工具接入](dshu.zh.md#tools)。 |
| 跨会话记忆 | 在记忆管理中按范围查询、编辑、停用或删除记录。自动提炼默认关闭。 |

<a id="settings-data"></a>
## 设置、数据与恢复

| 功能 | 入口和行为 |
| --- | --- |
| 工作步骤与用量 | 在通用设置中调整工作步骤的展开方式、收起时机和用量显示级别。新配置默认全部展开、收到下一条新消息时收起，并显示详细用量。 |
| 官方 API 日志选项 | 通用设置中的 Session Log 上传只适用于官方模型 API。新配置默认开启，已有的设置保持不变。 |
| 外观 | 可选浅色、深色、跟随系统或日出日落。各模式使用自己的主题色标识当前任务。 |
| 关于与版本 | 「关于」页显示作者 WaterRun、DSHU 与 DSH 版本、编译信息，以及源码和 REA 的来源。同一天有多个构建时，请同时核对版本号和提交。 |
| 备份与卸载 | DSHU 默认把独立数据保存在 `~/.dsh-uncensored`。更新前请先备份，卸载时按需选择保留或清理数据。[数据、更新与恢复](dshu.zh.md#data) |

首次配置请回到[使用手册](dshu.zh.md)。发布流程和候选验收见[首发打包交接](../../../.agents/requirements/windows-x64-first-release.md)。
