<a id="first-task"></a>
## 第一个任务

第一次用，建议挑个小而具体、做完能验证的任务，先确认模型连得上，再慢慢放开手脚。

1. **接上模型**：设置 → 模型，填好提供方、接口和凭据，保存后选一个模型。第三方接口记得选对协议、填对模型 ID，细节见[模型配置](providers.zh.md)。
2. **开个会话**：点侧栏的“新会话”，在输入框上方选工作区。要动项目文件就选项目目录；只是聊聊，选“不在工作区工作”就行。
3. **选个模式**：工作区旁边就是模式菜单。日常活用缺省，网安、逆向、写作各有专属手册和资料。
4. **把话说清楚**：要什么结果、手上有什么材料、怎样算做完。文件和截图一起附上，模型看不到你没给它的东西。
5. **验收**：看实际改了什么、跑了什么、还剩什么。工具报错、缺依赖、没跑的检查，留到下一轮处理。

举个例子，在项目工作区里发：

> 找到这个项目的入口和启动方式，解释当前构建失败的原因。修复后运行受影响的检查，最后列出修改内容、验证结果和仍未解决的问题。

> [!TIP]
>
> 靠谱的回复会落到具体文件和运行结果上，并且说明检查到底跑没跑。只给建议、没动手的，不算完成。

<a id="modes"></a>
## 四种模式

四种模式用的是同一套内置破甲提示词，区别在于带哪些工具、哪些工作手册、读哪些资料。手册按需加载，用到哪本读哪本。模型依然会犯错，最终以文件和运行结果为准。

| 模式 | 主题色 | 工作手册 | 资料 | 备注 |
| --- | --- | --- | --- | --- |
| 缺省 | 蓝 | 按需加载技能 | 当前工作区 | 读写文件、跑命令、查资料、拆任务 |
| 网安 | 红 | 七类现场手册 | `.security/<案件>/case.json` | 首次进入要确认；可选独立代理与目标保护 |
| 逆向 | 绿 | 八类分析手册 | `.reverse/<案件>/case.json` | 内置 REA，可接 Ghidra、IDA、Hopper |
| 写作 | 黄 | 七类写作手册 | `story/style/`、`story/bible/` | 不挂终端和代码执行 |

### 换模式的规矩

- 新会话默认缺省，第一条消息发出去之前随便换。
- 发出之后模式就锁住了，免得聊到一半工具和指令全变。真要换：设置 → 模式，打开“允许已有会话切换模式”，读完倒计时确认，等会话空闲再换。这个开关只管本次启动，重启后自动关闭。历史消息会保留，但可能和新模式对不上。
- 设置里的“模式说明”“如何使用”只是看说明，不会切换当前会话。
- “敏感操作需要确认”（设置 → 通用）默认开着，进网安、换模式前都会先问你一句。想关掉得等十秒倒计时，重新打开则立即生效。

### 缺省：日常使用和通用开发

把项目路径、错误现象和“怎样算完成”交代清楚，剩下的调查、修改、验证让它自己来。任务长的话，可以让它保留任务清单或计划，随时知道下一步是什么。

<summary>示例任务与验收要点</summary>

| 场景 | 可以这样说 | 验收时看 |
| --- | --- | --- |
| 修问题 | 调查搜索连续提交两次后结果消失的原因。先复现并解释原因，再完成必要的修复，运行相关测试，保留已有用户数据。 | 触发条件和原因、改了哪些文件、实际跑了哪些检查；复现不了的话缺什么条件 |
| 加小功能 | 给工作区选择器增加搜索。沿用已有样式，支持键盘操作和无结果状态，并检查窄窗口及正常桌面布局。 | 入口能用，有结果和没结果都清楚，原来的选择和草稿行为没坏 |
| 接着推进 | 阅读项目说明和当前 TODO，确认真实完成情况，继续下一项未完成工作，并更新交接记录。 | 做完的、没做完的、已知问题、验证结果和下一步分开列 |

</details>

### 网安：网络安全审计和攻击

第一次在新会话里进网安，会弹出“进入网安模式前的确认”：读完责任说明，看一眼境内网站保护的状态；保护没开或者状态不明时，还要照着提示输入一段声明。七类现场手册（交战流程、侦察、Web 攻击、网络利用、载荷实验、云与容器、报告）按调查阶段取用。手册教的是方法，里面提到的外部工具还得你的环境里真有。

- **案件记录**：`.security/<案件>/case.json` 存目标、证据、发现和备注，下次会话读进来接着查。在设置 → 模式 → 模式配置 → 网安里可以新建案件、编辑记录、生成 Markdown 报告，审阅过的备注能一键存进记忆。
- **独立代理**：同一页面填上 HTTP/HTTPS 上游代理，保存后可以测试连接。它只管网安会话访问目标的流量，模型请求、登录、余额查询、更新检查都不走它。“网安模式未开启此代理时提醒”默认关，开了之后网安会话顶部会一直提醒你。
- **流量记录**：能暂停采集、清空、筛选、看详情、导出 JSON。没被拦截的 HTTPS 隧道只记连接信息，没有正文。
- **目标保护**：境内网站、指定目标、生产资源的拦截规则默认全关，进网安也不会自动打开。打开之前，先看看[执行保护的覆盖与限制](../../../packages/guard/target-protection/README.zh.md)。

> [!WARNING]
>
> 网安模式执行的是真命令、访问的是真目标。软件不会替你判断目标有没有授权，请只在授权范围内使用。

<summary>示例任务与验收要点</summary>

| 场景 | 可以这样说 | 验收时看 |
| --- | --- | --- |
| 审应用 | 检查这个仓库的认证与上传流程，在本地测试环境复现可疑问题，指出受影响代码，完成修复和回归，并将发现记入案件记录。 | 定位到具体位置，用具体输入复现，有修改和回归；没复现的疑点明确标出来 |
| 查配置 | 检查这些部署文件中的凭据暴露、过度权限和不合理默认值，逐项解释、排出优先级，并给出具体修改与验证方法。 | 文件或配置项、证据、影响、确认修复的方法都有；静态检查和线上检查分开说 |
| 接着查 | 阅读当前工作区的安全案件记录，梳理已确认发现和待验证问题，继续下一步验证，并更新证据与报告。 | 新证据能对上发现，做了和没做的分清楚，旧证据不丢 |

</details>

### 逆向：逆向你要逆向的程序

先把原始样本留好，告诉它平台、架构线索和有代表性的输入，再说清楚想弄明白什么行为。只说一句“全部分析一下”，很难有像样的结果。八类分析手册：初筛、静态、动态、协议、补丁与注册机、移动端、恶意样本、案件簿。

- **内置 REA 6.9.0**：装好就有，每个逆向会话独占一个分析进程。设置 → 模式 → 模式配置 → 逆向里可以检测连接、看工具目录，按需指定 Ghidra、Java、IDA MCP 配置和原生分析引擎。改了配置会断开现有连接，之前打开的样本需要重新打开。
- **样本清点**：同一页面填工作区里的样本路径，只读字节，算出 SHA-256、格式、熵和可打印字符串，样本不会被执行。
- **分析案件**：`.reverse/<案件>/case.json` 存样本哈希、证据、发现和待验证的假设，也能生成报告。

> [!NOTE]
>
> “连接成功”只说明 REA 本身能用。Ghidra、IDA、Hopper 这些引擎要等真正打开样本时才检查版本和依赖，缺了会告诉你具体原因。外部引擎需要完全权限，随问不会启动它们。

<details>
<summary>示例任务与验收要点</summary>

| 场景 | 可以这样说 | 验收时看 |
| --- | --- | --- |
| 分析程序 | 检查这个样本，记录哈希与架构，定位解析器入口，结合证据说明主要调用路径，并把未决假设保存到案件记录。 | 样本身份、地址或偏移、引用或运行观察都有；没确认的结论附下一步实验 |
| 验证运行行为 | 使用 Frida 分析这个本地测试程序，跟踪目标函数的参数与返回值，并验证卸载脚本后程序恢复原有行为。 | 脚本可复用，观察值、复现方法、卸载结果齐全；附加失败要直说 |
| 还原协议 | 对比这些请求与响应样本，推断字段布局，编写独立解码器并用往返测试验证，尚不确定的字段单独记录。 | 偏移、长度、编码规则清楚，样例能跑；用没参与推断的样本验证 |

</details>

### 写作：写你想写的东西

七类写作手册：写作基本功、声音、场景、黑暗素材、连续性、文风参考、长篇结构。文风卡用措辞、句法、节奏、意象、对白、结构六条轴描述一种文风，再补上标志性手法、绝不会做的事和一段校准样例。

- **资料放哪**：`story/style/` 放文风卡，`story/bible/` 放人物、世界、时间线和已经定下的事实。
- **用哪些资料**：设置 → 模式 → 模式配置 → 写作，把 `story/` 下的文件“纳入列表”，再勾上“用于写作”。只有勾上的才会随请求发给模型；取消勾选或删掉记录，源文件都还在。
- **能用的工具**：读写文件、查资料、呈现文档。终端和代码执行不挂载，要跑脚本请换缺省模式。

<details>
<summary>示例任务与验收要点</summary>

| 场景 | 可以这样说 | 验收时看 |
| --- | --- | --- |
| 续写 | 沿用当前视角续写这一场，保持人物已知信息和未解决的张力，遵循选定设定，直接写正文，到访客离开时结束。 | 视角和人物认知一致，情节有推进，停在该停的地方，没把上一场再写一遍 |
| 修订 | 不改变事实与声音，收紧这一章，删除重复解释，改善对白，把连续性问题列在修订正文之后。 | 修订稿能直接用，修改意见单独列，情节改动在你点头前只算建议 |
| 规划长篇 | 根据提纲与人物表规划接下来六章，记录视角、时间、人物已知信息和未决线索，再完整写出第一章。 | 章节推进和连续性清楚，计划和正文分开放 |

</details>

<a id="conversations"></a>
## 旁问、随问与输入预测

主线在干活时，有三种方式插话：

| 入口 | 什么时候用 | 能看到主线的 | 怎么表现 |
| --- | --- | --- | --- |
| 主输入框 | 推进任务、提新要求 | 全部历史 | 任务跑着也能输入，怎么发取决于“忙碌时发送”设置 |
| `/side 问题` | 想多聊几句、讨论方案、附图提问 | 已经完成的进展 | 右侧开旁问并发送；只输 `/side` 是打开或重开 |
| `/btw 问题` | 只问一句，比如“进度如何” | 实时进度，正在跑的那步也算 | 只读，在输入框上方给一段简短回答 |
| 旁问里的 `/clear` | 旁问聊乱了，想重来 | — | 只清旁问自己的记录，新旁问照样能读主线 |

**旁问**沿用主线的模型、思考等级、权限和沙盒。每次提问前，它会同步主线刚完成的进展；自己的聊天记录单独存，关掉标签也还在，主线需要时也能翻看。想关标签就清空的话，打开设置 → 通用 → “旁问关闭后自动清除上下文”（默认关）。可以附图，前提是模型认得图。

**随问**是在任务**运行途中**用的，最常见的就是 `/btw 进度如何`。它读取主线的实时快照：在跑还是空闲、你最近一次提了什么要求、任务清单进度、最近调用的工具。它只有只读权限，回答默认不超过 512 token，思考等级默认“低”（设置 → 通用 → 随问思考等级）。每次 `/btw` 都是新的一问，新卡片替换旧卡片；随问不会出现在侧栏，删主会话时一起删掉。

**输入预测**会在你停下打字约 0.8 秒后给出灰色的后半句，按 <kbd>Tab</kbd> 收下，不会自动发送。主线、旁问、随问各自预测。以句号、问号、感叹号结尾，在敲别的斜杠命令，或者命令菜单开着的时候，它不会出来打扰。预测要调用模型、会计费，不想要可以在设置 → 通用里关掉。

> [!NOTE]
>
> 旁问里商量好的事，主线不会自动去做。拿定主意后，回主输入框交代一句就行。

<a id="spending"></a>
## 余额与额度限制

先分清三个数：**余额**是账户最近一次查到的钱，**对话费用**是本地估算的这个对话花了多少，**额度限制**是你给自己定的上限。三个都不是提供方的正式账单。

### 余额

侧栏的余额卡片显示充值余额（有赠金会另外列出），还会告诉你现在是官网的高峰还是低峰时段、离下次切换还有多久。高峰是工作日北京时间 09:00–12:00 和 14:00–18:00，周末和法定节假日都算低峰。点一下卡片立即刷新。

设置 → 额度里有一条本机采样的余额曲线，默认 15 秒采一次，可以设成 3 到 3600 秒。官方接口不提供历史余额，所以曲线从你第一次采样开始画。鼠标悬停、轻触，或者聚焦后按方向键，都能读出每个点的时间和金额。余额连续 30 分钟以上没动的区间会压缩（加起来最多占横轴五分之一）。压缩段能放下两段完整虚线时画成横向虚线，较短的段落保持实线，充值这类上涨用竖向虚线标出。注意余额的变化里可能混着充值、赠金和到期扣减，别直接当成某个对话的花费。

### 额度限制

如果你习惯使用各种 Coding Plan，有看额度百分比的癖好的话，DSHU 也提供了可选的额度限制功能，带来经典的 5h 和周限额，以及其它更多的限额选择。

| 窗口 | 15 分钟 | 1 小时 | 5 小时 | 1 天 | 7 天 | 30 天 |
| --- | --- | --- | --- | --- | --- | --- |
| 初始金额（元） | 5 | 15 | 50 | 100 | 500 | 2000 |

新装时全部关闭；5 小时和 7 天排在前面，其余展开就能看到。每档都能单独开关、改金额、重置，底部还有“全部关闭”和“全部重置”。所有会话和本机进程共用这些额度，关掉某档不会删掉它的历史。

每个请求发出前，会按上下文上限和最大输出先预留一笔，回来后按实际用量结算，所以正在跑的请求会暂时占一点额度。估算和预留的具体算法见[额度控制说明](../../../packages/guard/spend-limit/README.md)。

### 额度用完了

对话会暂停，输入框上方的横幅写明原因和预计恢复时间（能估出来的话），侧栏显示“正在等待额度”。你可以等窗口滚过去，也可以点“重置限额统计并继续”或“调整限额”。只有打开了**自动恢复**（默认关），额度回来后才会自己接着跑；如果只是在等别的请求结算释放预留，结算完也会继续。

> [!CAUTION]
>
> 重置只是把本地计数清零，不会充值，也不会退回提供方已经扣掉的钱。提供方那边余额见底、认证失败、网络断了，这些是另一回事，重置本地计数解决不了。

<a id="memory"></a>
## 记忆与模式资料

**跨对话记忆**存的是长期有用的信息，之后的对话需要时自己查；**模式资料**存的是眼下这份工作要参考的东西。两者都有明确的适用范围，不会把别的对话整段塞进来。

- **管理记忆**：设置 → 通用 → 管理记忆。分偏好、项目事实、操作结论、写作设定四类；范围可以是全局，也可以限定到某个工作区、某种模式，或者两者都限定。支持搜索、筛选、新增、编辑、停用和删除。
- **自动提炼**：默认关。打开后每轮对话结束会让当前模型整理一遍长期事实，存到当前工作区和模式下；会计费，也受额度限制。随问这类临时对话既不查记忆，也不提炼。
- **网安备注**：案件里审阅过的备注可以“存入记忆”，默认只在当前工作区和网安模式下可见；完整证据还是以案件文件为准。
- **写作资料**：只有勾上“用于写作”的文风卡和设定会发给模型。

回复沿用了错误的背景？先查查勾选的资料、记忆的范围和旁问的记录，再决定是改记忆、取消勾选，还是在旁问里 `/clear`。删会话和改记忆是两回事，删了对话，记忆还在。

<a id="sessions"></a>
## 会话与工作区

| 想做什么 | 怎么做 |
| --- | --- |
| 开新会话 | 侧栏“新会话”，在输入框上方选工作区（可以加目录，也可以不在工作区工作）和模式 |
| 找会话 | 工作区标题旁的搜索和筛选按钮，按名称或路径找；可以隐藏归档、显示全部或只看归档 |
| 认模式 | 每个会话左边有一条模式色：蓝缺省、红网安、绿逆向、黄写作；灰色半截表示还没发过消息 |
| 置顶与排序 | 置顶的排最前；普通会话在各自区域里拖动排序。手动排序和“按最近更新”是两种独立的方式 |
| 改名、复制 ID | 右键会话，或点行尾的菜单 |
| 分叉 | 从会话菜单分叉，从最近一次完成的回合起步；从消息下方分叉，从那条消息起步。新分支继承原来的模式 |
| 归档 | 会话菜单 → 归档会话；在跑的会先问你要不要停。之后在归档筛选里能找回来 |
| 删除 | 会话菜单 → 删除对话 → 停止并删除。先停下相关工作，再把会话连同旁问、随问、子会话一起永久删掉；独立的分叉和工作区文件不受影响 |
| 移除工作区 | 工作区菜单里操作，里面的会话会挪到“未分组” |
| 看谁在忙 | 侧栏会标出运行中、等审批、计划待审、等你回答的会话；项目行可以直接打开进行中的对话 |

删之前看清楚标题和关联范围；只是不想看见，用归档就好。删除和分叉的实现细节见[会话控制说明](../../../packages/api/session-controller/README.zh.md)。

<a id="tools"></a>
## 工具、插件与 REA

插件可以加模型提供方、工具和界面，MCP 用来接外部工具服务。配好之后，先拿一个小任务试试，看执行后端、输出和报错是否正常。插件在列表里、工具在目录里、真能把活干完，这是三件不同的事；外部程序、凭据和许可证都得各自到位。

独立代理只在适用的执行路径上生效：有连接记录不代表看过加密正文，终端程序也得遵守代理变量才会走代理。REA 的版本、仓库和来源提交见“关于”页和 [REA 说明](../../../packages/mcp/rea/README.zh.md)。

<a id="data"></a>
## 数据与更新

DSHU 有独立的程序标识和数据目录，默认放在 `~/.dsh-uncensored`，想换位置就设环境变量 `DSH_UNCENSORED_HOME`。和官方版装在一起没问题，两边的配置和会话互不共享。注意，备份应用数据不等于备份了工作区文件、外部工具的数据和提供方的账单。

版本号是 `YYYY.MM.DD.N`，最后一位是当天的第几个构建。账号菜单 → 关于，可以看到 DSHU 版本和编译时间、基于哪个 DSH 版本、源码节点和有没有本地修改、dsh-purge Community 版本与来源、内置 REA 版本，也能直接检查 GitHub 上有没有新版；被 GitHub 限流时会告诉你多久后能再试。

> [!IMPORTANT]
>
> 更新前先关掉 DSHU，备份数据目录和重要的工作区文件。只用标明 DSHU、且和你平台匹配的安装包；卸载时留意数据清理选项。正式签名、在线升级、系统重启和自动回退还没完成发行验收，眼下的验证和恢复办法见[交付记录](../../../.agents/HANDOFF.md)。别让旧版程序去写新版的数据。

<a id="troubleshooting"></a>
## 常见问题

遇到问题，先记下报错原文、发生时间、用的哪个模式、怎么复现，再判断是模型、工具、额度还是界面的事。反馈时附上截图和版本号，凭据记得打码。

| 现象 | 先看 | 再做 |
| --- | --- | --- |
| 模型不回话 | 提供方、模型 ID、接口协议、凭据、原始报错 | 照[模型配置](providers.zh.md)逐项对；重置额度解决不了认证失败和限流 |
| 提示“此模型没有可用的人民币费率” | 是否开了额度限制，当前模型有没有配费率 | 给这个模型配上费率，或者关掉额度限制 |
| 任务停着不动 | 额度横幅、开了哪些窗口、有没有在途预留 | 等结算或窗口滚过去；需要时重置对应窗口，顺便看看自动恢复开没开 |
| `/side 问题` 没反应 | 是不是在主输入框发的、旁问标签开没开 | 只输 `/side` 重开旁问看看；想从头来就在旁问里 `/clear` |
| 旁问看不懂图 | 附件加上没有、模型支不支持图像 | 换个支持图像的模型，并说明要看图里哪儿 |
| `/btw` 提示要输入问题 | `/btw` 后面有没有内容 | 写成 `/btw 进度如何` 这样的完整问题 |
| 看完模式说明，模式没变 | 当前会话的模式和锁定状态 | 看说明不会切换；新会话在发送前选，已有会话要先临时允许切换 |
| 网安资料提示“有文件格式损坏” | `case.json` 是不是被手改坏了 | 用手册附带的 `casefile.mjs` 或设置页重新整理 |
| REA 连上了但分析失败 | 对应引擎的路径、运行环境、权限、许可证 | 拿小样本试一下，保留完整报错；能找到引擎不等于引擎能用 |
| 删除会话报错 | 会话、子任务、执行状态和提示信息 | 截图带上版本号[反馈问题](https://github.com/Water-Run/deepseek-harness-uncensored/issues/new/choose)，别手动删数据库文件 |
| 余额曲线有空缺 | 是不是刚开始采样、是不是被压缩的平稳区间 | 继续采就好；没采到的时段，接口也补不回来 |
