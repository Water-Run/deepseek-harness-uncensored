# DSHU 使用手册

[English](dshu.md) | 中文

## 概述

DSHU 是 WaterRun 维护的 DeepSeek Harness 独立分支，内置破甲提示词，提供四种模式和独立的桌面应用。本手册从已安装桌面版或已启动 Web 服务开始，依次介绍模型配置、任务组织、辅助对话、费用控制和长期资料管理。DSHU 与官方版的配置和会话互相独立；模型能力、接口可用性和费用由所用提供方决定。交付版本与验收范围以[开发清单](../../../.agents/TODO.md)为准，源码中尚未发布的改动不一定已进入安装版。

<a id="first-task"></a>
## 完成第一个任务

第一次使用时，挑一个范围明确、结果可以检查的任务。先确认模型连接正常，再逐步扩大任务范围。

1. 打开 **设置 → 模型**，填写提供方、接口与凭据，保存后选择模型。第三方接口还需要选对协议并填写正确的模型 ID，详见[模型配置](providers.zh.md)。
2. 新建会话并选择工作区。处理项目文件时选择项目目录；一般问答可以选择 **不在工作区工作**，不必为此专门创建目录。
3. 发送第一条消息前选择模式。日常任务用缺省模式；网安、逆向和写作各有专属资料与工作流程。已有会话默认保持原来的模式。
4. 写清楚输入、期望结果和验证方式后发送。需要的文件或图片要一起附上，模型不会读到你没有提供的资料。
5. 检查实际修改、执行结果和未完成事项。工具报错、缺少依赖或没有运行的检查，留作下一步任务。

例如，在一个已有项目的工作区中发送：

> 找到这个项目的入口和启动方式，解释当前构建失败的原因。修复后运行受影响的检查，最后列出修改内容、验证结果和仍未解决的问题。

可靠的回复会指向具体文件或观察结果，并说明检查是否真的运行过。只给出建议，不代表已经修改或验证。

<a id="modes"></a>
## 选择模式

模式决定专属资料、工作流程和可用工具。四种模式共用内置破甲提示词，但模型仍会出错，结果要以文件、运行记录和复核为准。设置中的 **模式说明** 和 **如何使用** 只打开指南，不会切换会话；已有会话需要先临时允许切换，并且在空闲时才能更换模式。

### 缺省：开发与日常任务

![缺省模式，主题色蓝](../../assets/dshu/mode-default.svg)

缺省模式可以读写文件、运行命令、检索资料，并按需使用协作和工作流，适合修复程序、理解代码仓库、整理资料和完成可交付的修改。先给出项目路径、错误现象和完成标准，再让智能体调查、修改并验证。

> 复现这个接口返回错误的问题，找出原因，修复后验证正常输入和异常输入。只凭阅读代码得出的推断，不要写成实际运行的结果。

**验收要点：** 修改的文件、触发条件、验证命令和结果齐全；没能运行的检查要写明原因。

### 网安：调查、证据与验证

![网安模式，主题色红](../../assets/dshu/mode-security.svg)

网安模式提供七类现场手册、案件记录、报告和独立代理。首次进入新的网安会话需要确认责任声明。案件保存在 `.security/`，记录目标、证据、发现和待办，之后的对话可以接着使用。能完成哪些任务取决于提供方、模型和实际执行环境；手册本身不会安装外部工具。

> 检查这个测试应用的认证和上传流程，在本地复现可疑问题，指出受影响的位置，完成修复和回归测试，并把证据和未解决的问题写入案件记录。

**验收要点：** 每个发现都对应到目标、位置和复现条件，并区分观察、推测和未能执行的验证。独立代理需要在模式配置中单独启用，顶部的未启用提醒可以开关。目标、服务器和数据库保护默认关闭，进入网安模式不会自动开启；启用前请先核对[执行保护的覆盖与限制](../../../packages/guard/target-protection/README.zh.md)。

### 逆向：样本、调用路径与协议

![逆向模式，主题色绿](../../assets/dshu/mode-reverse.svg)

逆向模式提供八类分析手册、`.reverse/` 案件记录和内置 REA，用于分析程序行为、文件格式、协议和运行时观察。先保留原始样本，提供平台、架构线索和有代表性的输入，再选择合适的工具；修改过的样本和产物另行保存。

> 记录这个样本的哈希和架构，定位解析器入口，追踪关键调用，用独立的输入验证结论，并保存脚本和尚未证实的假设。

**验收要点：** 样本身份、地址或偏移、调用或运行证据、可复用的脚本以及不确定之处都交代清楚。REA 已内置；Ghidra、Java、IDA、Hopper 等可选引擎需要分别配置。连接检测通过，不代表每个引擎、许可证和目标进程都已就绪。

### 写作：设定、文风与长篇延续

![写作模式，主题色金](../../assets/dshu/mode-writing.svg)

写作模式面向小说、剧本和长文，提供参考文风、六轴风格卡和 `story/bible/` 设定集。只有选中的资料会进入模型请求。在模式配置中管理参考与设定后，之后的对话可以沿用这些资料继续。写作模式不挂载终端和代码执行工具。

> 按选定的人物设定和参考文风续写下一场。保持当前视角、时间线和人物已知的信息，检查与设定冲突的地方，并给出完整正文。

**验收要点：** 正文符合要求的篇幅、视角和人物关系；设定冲突和待确认的信息单独列出。长篇作品先整理人物、时间线和世界规则，再逐场推进。

<a id="conversations"></a>
## 主线、旁问与随问

主线负责推进任务，旁问用于连续讨论，随问用于临时确认。旁问和随问都不会把主线历史复制成侧栏里的普通会话。

| 入口 | 适合 | 历史与行为 |
| --- | --- | --- |
| 主输入框 | 推进当前任务、提出新要求 | 保留主线历史；任务运行中发送的处理方式取决于“忙碌时发送”设置。 |
| `/side 问题` | 连续追问、解释或附图提问 | 打开旁问并发送问题；只输入 `/side` 则打开或重开旁问。 |
| `/btw 问题` | 一次简短确认 | 在主会话中显示简短回答，不新建普通会话。 |
| 旁问中的 `/clear` | 重新开始旁问 | 只清空旁问自己的历史；主线历史保留，旁问仍能参考主线。 |

旁问每次提问都会参考主线已完成的新进展，并独立保存自己的历史。主线也可以主动查看对应的旁问。注意：在旁问里讨论某个操作，并不等于向主线下达了新的执行指令。

关闭旁问默认保留历史，重新打开即可继续。如需关闭时自动清理，在设置中开启 **旁问关闭后自动清除上下文**（默认关闭）。`/clear` 只在旁问中可用，不能清理主会话。

旁问支持附图。附图时说明要检查的位置或现象，并使用支持图像输入的模型；附件添加成功，不代表提供方一定支持该类型。

![随问的简短回答显示在主会话中](../../assets/dshu/quick-question-light.png)

<a id="spending"></a>
## 余额、对话费用与限额

这三项回答的是不同的问题：余额是账户的最近一次采样，对话费用是本地估算的任务花费，限额是你自行启用的本地支出控制。三者不能互相替代，也都不是提供方的正式账单。

### 查看余额与曲线

侧栏的余额卡片很紧凑，点击可查看统计或刷新。默认每 15 秒采样一次，最短可设为 3 秒。公开 API 不提供完整的历史记录，曲线由本机采样逐步积累；悬停、轻触，或聚焦后使用方向键，可以查看具体时间和金额。

充值等余额增加用竖向虚线标出；长时间没有变化的区间用横向虚线压缩，避免平稳时段挤占之前的变化。余额差可能包含充值、赠金和到期扣减，不能直接当作本次对话的费用。

### 设置独立限额

**设置 → 额度** 提供 15 分钟、1 小时、5 小时、1 天、7 天和 30 天六档窗口。新安装时全部关闭；5 小时与 7 天显示在前，其余可以展开。每档都能单独启用、修改金额和重置，底部另有全部关闭和全部重置。

每次请求执行前先预留估算费用，返回用量后再结算，所以进行中的请求可能暂时占用额度。重置只清零本地限额统计，不会充值，也不会撤销提供方已收取的费用。费用估算、预留和失败处理的规则见[额度控制说明](../../../packages/guard/spend-limit/README.md)。

### 达到限额之后

额度不足时，暂停横幅会显示原因、预计恢复时间（如可估算）和快捷重置。可以等待滚动窗口恢复，也可以确认后调整、关闭或重置对应的限额。只有开启自动恢复时，额度恢复后才会自动继续被暂停的任务；其他请求结算后释放的预留也可能让额度重新可用。

点击底栏的金额可以展开当前对话的费用曲线，点击限额项可以查看已启用窗口的进度。提供方余额耗尽、认证失败和网络故障是另外的错误，需要按具体错误处理，重置本地统计无法解决。

<a id="memory"></a>
## 记忆、资料与输入预测

跨对话记忆保存可以检索的长期信息，模式资料保存当前工作需要的参考，两者都要明确适用范围。它们不会把其他会话的完整历史自动附加到每次请求中。

- **长期事实与偏好：** 使用结构化记忆，按范围检索、审阅和编辑。自动提炼默认关闭；开启后产生的模型调用按提供方规则计费。
- **项目或案件的详细证据：** 保存在工作区，或 `.security/`、`.reverse/` 的案件文件中。选中的网安案件备注可以经审阅后存为记忆，默认限定在当前工作区和网安模式；完整证据仍以案件文件为准。
- **写作资料：** 在模式配置中选择参考文风和设定，不需要的就取消选择。仅仅保存在列表里、没有选中的资料，不会进入模型请求。
- **输入预测：** 默认开启，主线、旁问和随问分别根据各自的草稿预测。灰色文字只是建议，按 Tab 填入后仍由你决定是否发送；预测会调用当前模型，可能产生费用。

如果回复沿用了错误的背景，先检查已选资料、记忆范围和旁问历史，再决定是编辑记忆、取消选择资料，还是在旁问中使用 `/clear`。删除会话和编辑长期记忆是两种不同的操作。

![通用设置中的输入预测开关](../../assets/dshu/input-prediction-settings-light.png)

<a id="tools"></a>
## 工具、插件与 REA

桌面版已内置 REA，无需另行安装。在 **设置 → 模式 → 逆向配置** 中可以检测连接，并按需指定可选引擎；版本、仓库和固定的来源提交见关于页和 [REA 说明](../../../packages/mcp/rea/README.zh.md)。修改配置会重建连接，之前打开的样本需要重新打开。

插件可以扩展模型提供方、工具和界面，MCP 用于连接外部工具服务。配置完成后，先运行一个范围明确的小任务，核对执行后端、输出和失败提示。插件出现在列表中、工具出现在目录中和真正完成任务，是三项不同的检查；外部程序、凭据和许可证仍需各自满足要求。

网安独立代理只在适用的执行路径上生效。记录了连接元数据，不代表已经检查过加密的正文；终端程序也必须遵守代理配置才会经过代理。可选保护的设置页会显示各执行器的覆盖情况，尚未覆盖的协议、远端环境和入站场景，不能仅凭开关认定已受保护。

<a id="defaults"></a>
## 外观与默认设置

模式色用来区分任务：缺省为蓝、网安为红、逆向为绿、写作为金。外观可选跟随系统、浅色、深色和日出日落；各模式的指南使用对应的主题色，阅读指南不会改变当前会话。

| 设置 | 新安装默认值 | 说明 |
| --- | --- | --- |
| 新会话模式 | 缺省 | 发送第一条消息前可以改选其他模式。 |
| 已有会话切换模式 | 不允许 | 在设置中临时允许，并等会话空闲后才能切换。 |
| 六档支出限额 | 全部关闭 | 5 小时与 7 天只是优先显示，并没有自动启用。 |
| 额度自动恢复 | 关闭 | 开启后，额度恢复时自动继续被暂停的任务。 |
| 目标、服务器与数据库保护 | 关闭 | 属于可选的进阶配置，需按执行器核对覆盖。 |
| 余额采样间隔 | 15 秒 | 最短可设为 3 秒。 |
| 输入预测 | 开启 | 调用当前模型，可能产生费用。 |
| 旁问关闭后清理 | 关闭 | 需要时可在旁问中手动发送 `/clear`。 |
| 自动记忆提炼 | 关闭 | 开启前先选好范围，并审阅保存的结果。 |

以上只是新安装时的初始值。更新会保留已有配置，因此不能据此推断当前的开关状态。

<a id="data"></a>
## 数据、更新与恢复

DSHU 使用独立的程序标识和数据目录，默认数据根目录为 `~/.dsh-uncensored`，可以用环境变量 `DSH_UNCENSORED_HOME` 改写。官方版和 DSHU 可以同时安装，配置与会话不会自动共享。应用数据的备份不一定包含工作区文件、外部工具的数据和提供方的账单记录。

版本号格式为 `YYYY.MM.DD.N`，末位是当天的构建序号。关于页分别显示 DSHU 版本、所基于的 DSH 版本、作者 WaterRun、编译信息和依赖来源；日期版本不取代 DSH 或 REA 自己的版本号。

更新前请关闭 DSHU，并备份数据目录和重要的工作区文件。使用明确标为 DSHU、且与平台匹配的安装包；卸载时留意数据清理选项。正式签名、在线升级、系统重启和自动回退尚未完成发行验收，当前检查包的验证与恢复方法见[交付记录](../../../.agents/HANDOFF.md)。不要让旧版程序直接写入未经验证兼容的新版数据。

<a id="troubleshooting"></a>
## 故障排查

先记下实际的错误信息、发生时间、所用模式和复现步骤，再判断问题出在模型、工具、额度还是界面。反馈时可以附上截图和版本信息，凭据请先脱敏。

| 现象 | 先检查 | 下一步 |
| --- | --- | --- |
| 模型没有响应 | 提供方、模型 ID、接口协议、凭据和原始错误 | 按[模型配置](providers.zh.md)逐项检查；重置本地额度无法解决认证失败或服务端限流。 |
| 任务暂停不动 | 额度横幅、已启用的窗口、进行中的预留 | 等待结算或窗口恢复；按需重置对应窗口，并检查自动恢复开关。 |
| `/side 问题` 没有出现预期内容 | 是否在主输入框发送、是否打开了对应的旁问 | 只输入 `/side` 重开旁问核对；需要全新历史时在旁问中发送 `/clear`。 |
| 旁问无法识别图片 | 附件是否添加成功、当前模型是否支持图像 | 换用支持图像的模型，并说明要检查的位置和目的。 |
| 阅读模式指南后模式没变 | 当前会话的模式和锁定状态 | 阅读指南不会切换模式；新会话在发送前选择，已有会话需临时允许切换。 |
| REA 已连接但分析失败 | 对应的引擎、路径、运行环境、权限和许可证 | 用小样本检查实际执行并保留完整错误；能发现引擎不等于引擎可用。 |
| 删除会话时报错 | 对应的会话、子任务、执行状态和错误提示 | 保留截图和版本信息并[反馈问题](https://github.com/Water-Run/deepseek-harness-uncensored/issues/new/choose)，不要手动删除数据库文件。 |
| 余额历史不完整 | 是否刚开始采样、是否存在被压缩的平稳区间 | 继续积累采样；公开接口无法补回未采样时段的余额历史。 |
