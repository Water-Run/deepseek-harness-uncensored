# 内置余额服务

## Summary

提供赠金、充值余额和本机历史记录。登录账号优先，否则使用配置的 API Key；凭据不会返回给界面。

## 使用

随 Web 和 Desktop 默认加载。刷新间隔默认 15 秒，可设置为 3–3600 秒的整数。采样和侧栏显示各有独立开关，可读取本机记录或从 API 实时采样。公共余额 API 只提供当前余额，曲线从本机开始采样后累积。

保存新采样时默认清理 30 天以前的记录，显式选择关闭或按条数清理的配置继续生效。设置页返回全部保留记录。侧栏默认显示，按最近一次采样向前取 7 天，可选 1 天或 30 天，超过单次传输上限时，保留首尾采样，并优先保留较近的余额回升前后采样。其余位置均匀补点。本机历史仍保存原始小数和时间。

## Model Experience

不添加模型工具或提示词，不改变对话内容或 KV 缓存。查询余额不启动模型请求。

## Known Limitations and Deferred Work

本机历史不能回溯首次采样前的数据。API Key 更换后使用独立历史；重新使用原 Key 可读取它原有的记录。
