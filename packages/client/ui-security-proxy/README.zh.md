# @deepseek-ai/dsh-client-ui-security-proxy

[English](README.md) | 中文

## 概述

本插件在模式卡片下方渲染网安模式自己的网络设置：启用开关、协议、地址、端口、由凭据系统保存的密码、以真实代理状态为准的连接检查、如实的覆盖范围列表，以及有界的已捕获交换查看器。提醒开启时，网安对话顶部持续显示独立代理未开启的横幅。横幅开关可关闭提醒，不改变代理状态。

<a id="use-this-package"></a>
## 使用本包

Web 应用以浏览器行加载，无需另行安装。该区域注册进 `settings.mode.materials`，也就是预设卡片下方的模式资料座；只有当前选中模式是 `security` 时才绘制。它使用的 Remote 命名空间是 [`@deepseek-ai/dsh-security-proxy-local`](../../guard/security-proxy-local/README.zh.md) 的 `securityProxy`。

目标设置在首次打开面板前不发起读取。重新连接只刷新已经使用的设置，并丢弃旧连接的迟到回复。目标保护面板使用[可选受控 Web 配置](../../guard/target-protection/README.zh.md#use-this-package)。应用所有者可配置境内保护、新增和编辑生产或测试规则、管理别名，并查看当前规则版本与地区数据。「检查数据更新」独立更新托管数据，保留规则草稿。面板分别显示受控网页抓取与受控独立代理的挂载状态。入口撤下时刷新状态、保留草稿并禁用保存。点击「保存规则」才提交草稿。遇到版本冲突或连接切换时，页面保留草稿并禁止覆盖当前服务的规则。

准入审计默认折叠。展开后读取最近最多 100 条记录，并在 Host 状态变化时自动刷新。折叠后暂停自动读取。可按判定结果筛选，或搜索目标、指纹、规则 ID 与原因代码。每条记录可展开查看规则版本、检查阶段和完整标识。刷新失败会保留已读数据，重新连接会清除上一服务的记录。审计无法写入时持续显示提示。

本机执行状态显示 Host 已挂载的文件提供方与命令/终端策略。准入检查、原生网关出站和原生禁网分别展示。原生命令启动时仍会检查平台支持和目标规则。旧版 Host 省略执行状态时，只展示其报告的 HTTP 入口。

SSH 与数据库覆盖默认折叠。SSH 显示已验证连接数及启用远端路径规则的连接数，断连或撤销后移除计数。SQLite、PostgreSQL 和 MySQL 分别显示已配置绑定数或提供方缺失。实际操作仍会核验目标、连接和访问权限。旧版 Host 不提供这些字段时隐藏此组。

命令覆盖项包含一次性命令和持久 shell 终端，需由应用遵守代理环境变量；已捕获的 HTTP 与保持加密的 HTTPS 隧道分别标注。

桌面原生页面在流量列表中标为「侧栏浏览器」。Web 内嵌页与附加的外部浏览器不使用此代理。

MCP 覆盖项说明会话代理承载的 HTTP 工具和资源请求，以及传给 stdio 服务的代理环境变量。启动发现走应用路由。

外部委派覆盖项包含 ACP、Codex、Claude Code 和 DSH SDK 启动并遵守代理变量的子进程。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节 —— 点击展开</summary>

`controller.ts` 拥有该区域的读取与写入。设置读取、筛选列表和详情分别维护代际，仅当前请求可以发布数据或错误。关闭详情或清理捕获记录会使其待返回回复失效。清理成功后，较早的设置回复也不能恢复清理前的计数；有效列表回复同时刷新显示的捕获计数。设置写入使用单一串行槽。`SecurityProxySection.tsx` 通过注入的 `hooks` 组件从该存储渲染；组件本地状态只保存未保存的草稿与密码输入。

列表读取失败时保留可用设置和记录；清理失败时保留已显示的记录和详情。设置保存确认与随后的流量刷新分别处理。

查看器展示 Host 存储的请求/响应头原文、有界正文、仅 CONNECT 行的隧道说明，以及明确的截断标记。交换详情分别显示 HTTP 状态码和传输结果。Host 提供阶段信息时，截断提示显示受影响的正文及触及的采集或保存上限。隧道行绝不伪装携带正文。设置反馈使用共享 toast 原语。提醒使用 `conversation.mode.notice`，读取当前对话模式并共享设置控制器；开启代理或关闭提醒后隐藏。

「导出 JSON」通过共享文件操作服务保存符合当前筛选的全部留存记录，不受界面列表条数限制。提供方执行[导出字节上限](../../guard/security-proxy-local/README.zh.md#use-this-package)。读取或保存失败时保留记录并允许重试。切换 Host 会清除设置、记录、筛选、密码和未保存的代理草稿；旧连接回复不能发布数据或启动下载。退出时等待已接收的文件保存完成，再释放文件操作服务。

全部文案都在带类型的语言字典（`en`/`zh`）中，组件内没有硬编码界面文字。

</details>

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **导出范围** —— JSON 包含 Host 尚未清理且符合筛选的记录，包括已存储的头部、有界正文和隧道说明；不恢复已过期记录，也不导入其他 Host。
- **记录仅在内存** —— 重启会随 Host 的捕获存储一并清空列表。
- **依赖模式资料座** —— 该区域注册进模式设置页渲染的 `settings.mode.materials`，只有选中模式为 `security` 时才绘制。
- **提醒展示** —— 持续横幅需要已连接的图形界面；不改变命令行执行或代理路由。
