# 记忆管理设置行

通用设置中的一行“跨对话记忆”，打开管理面板后可搜索、按范围与类型筛选、新增、编辑、启用或禁用、删除记录。设置仍保持通用、模型、额度、模式、插件五个分组，不新增一级入口。

状态来自注入的快照存储：列表与筛选结果只在 Host 确认写入后更新；草稿由控制器持有，因此离开页面再回来不会丢失正在编辑的内容。版本冲突会保留用户输入并显示可重试的提示。错误映射为固定文案键，界面文案全部走本地化字典。

## Known Limitations and Deferred Work

- 范围选择使用原生下拉框，尚未换用共享菜单组件；窄窗口下会换行。
- 未提供来源会话的跳转或“来源已删除”标记。
- 面板为模态框实现，未做独立的设置子页；模式专属记忆页留待后续接入同一控制器。
