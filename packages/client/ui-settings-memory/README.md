# 记忆管理设置行

通用设置中的一行“跨对话记忆”，打开管理面板后可搜索、按范围与类型筛选、新增、编辑、启用或禁用、删除记录。设置仍保持通用、模型、额度、模式、插件五个分组，不新增一级入口。

“自动提炼记忆”默认关闭，开启后额外使用当前模型并计费。管理页显示打开会话的提炼状态，失败或取消时可重试；来源会话需要保持打开且空闲。模式资料页可以直接打开同一管理器并带入模式筛选。设置与重试的结果由根层提示通知呈现，关闭对话框不会丢失通知。

状态来自注入的快照存储：列表与筛选结果只在 Host 确认写入后更新；草稿由控制器持有，因此离开页面再回来不会丢失正在编辑的内容。版本冲突会保留用户输入并显示可重试的提示。错误映射为固定文案键，界面文案全部走本地化字典。

范围、类型和模式选择使用共享应用菜单，支持主题、键盘与焦点恢复。管理读写仅限应用所有者；面板明确说明删除对话不会自动删除记忆，删除记忆也不会改写已有日志。

## Known Limitations and Deferred Work

- 来源状态区分存在、缺失与无法核验；暂未提供来源会话的跳转。
- 提炼状态来自打开的会话，管理页刷新后读取最新结果。旧会话未打开时不提供后台重试。
