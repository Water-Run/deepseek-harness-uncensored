# @deepseek-ai/dsh-target-protection

[English](README.md) | 中文

## 概述

这个可选后端保护 HTTP 和本地文件操作中的生产目标。它将 DNS 绑定到连接地址，支持本地国家数据，并在审计规则下允许结构化文件读取。生产限制优先于测试例外；无法约束操作范围的任意进程会被拒绝。默认产品不装配此集成，仅覆盖显式装配的受控提供方。

## 使用本包

装配根服务时，通过 `path` 明确指定独立的 SQLite 规则库。与 Web 服务一起装配 `./http`，替换普通 HTTP 抓取提供方。两者使用同一个 ID，不能同时装配。受控消费者必须依赖 `targetProtection`；移除该服务会撤下消费者，而不会恢复无保护抓取。

[可选 Web 配置](../../../apps/cli/config/examples/target-protection.yml) 会装配受控提供方。在源码目录执行 `pnpm dsh web --patch apps/cli/config/examples/target-protection.yml` 启动。初始规则为空，境内保护关闭。此配置为保护规则文件而拒绝效果无法约束的本地执行。实际检查由已装配的适配器执行。

在「设置 → 模式 → 网安 → 目标保护」查看当前数据来源、编辑规则并按草稿对应的版本保存。

`./settings` 向已认证的应用所有者提供 `targetProtectionSettings.get` 和 `configure`。`get` 返回已提交规则、版本、HTTP 路由的实时状态及 DB-IP 署名和数据时效。`configure` 接收完整的 `preferences` 和 `expectedRevision`，提交前拒绝过期编辑或断开的所有者。只有两条受控 HTTP 路由均就绪且地区数据有效时，网安确认才显示境内保护已启用。数据过期或路由撤下时显示不可用。规则提交后，已打开的首次确认失效。

设置 `auditPath` 可启用独立的本机准入日志。可选 Web 配置已提供该路径。`auditLimit` 默认保留最新 2000 条。每条记录包含判定采用的规则版本、操作、阶段、结果代码、最多 64 个命中规则 ID 和总命中数。日志排除原始主机、路径、凭据与错误详情。带密钥的指纹可关联重启前后的同一目标。`targetProtectionSettings.auditHistory` 向已认证的应用所有者返回最近最多 100 条。

审计覆盖受保护的 HTTP、代理 HTTP、端点、本机文件及无法约束执行的检查。预检通过会省略，准入结果和工具执行结果分别记录。已启用的审计库写入失败时，会拦截新的放行操作，所有者可以查看不可用状态。恢复审计库后重启即可继续使用。

在「设置 → 模式 → 网安 → 准入审计」查看最近的判定。读取条目带有数据库分配的稳定 ID。

装配 `agents` 时，审计检查在等待前捕获当前进程内的发起会话。判定保留其 ID 和记录的父会话，并在返回准入前向该会话追加 `target/admission`。并发主线、旁问、随问和子任务各自保留记录。这些仅写日志的事件不进入模型历史。旧记录与未绑定会话的调用省略 `source`，不会推断所属对话。

开启审计时，工具执行包装采用工具明确携带的 Agent，独立调用则清除继承的归属。父会话调用另一个 Agent 的工具，不会接收子会话的审计记录。

可信监听器所有者通过 `bindAuditSession` 捕获准确的存活 Session。受控网安代理将此绑定用于受控抓取、子进程 HTTP 和 CONNECT 流量，连接检查明确不归属对话。关闭或替换会话会拒绝新请求，并取消尚未放行的判定。原会话已关闭时，终止记录保留在本机审计库，不会停用其他对话的审计。绑定请求结束后才关闭审计库。此机制记录监听器分配的会话，不验证使用未认证回环端口的其他本地进程身份。其余未绑定的 Worker 仍需接入各自所有者。

绑定提供的取消信号覆盖响应正文、CONNECT 与受检查 HTTPS，直到传输清理完成。会话观察器由保护提供方拥有，借用服务的 Agent 退出时不会在会话关闭前移除观察器。原生提供方在排队准备前捕获已注册的调用者作用域，并把私有网关绑定到该 Session。`DSH_SESSION_ID` 等环境值不能覆盖归属；无作用域的 Host 进程仍不分配对话。未启用记录或缺少归属时，`currentAuditSessionId` 返回 null。

审计库在事务中从版本 1 升级到 2，保留记录和指纹密钥。使用旧审计实现须恢复升级前备份。旧 Session 读取器会在回放前拒绝新增的必需事件；含有 `target/admission` 的会话须继续使用当前运行时。发起会话拒绝追加审计时，也会停止新的放行操作，修复后重启 Host 才能继续。

`busyTimeoutMs` 限制 SQLite 锁等待（默认 1000）；`checkTimeoutMs` 限制地址检查（默认 5000）；`maxRechecks` 限制并发配置变化后的复查次数（默认 3）。这些选项不授权重放网络操作。

`dnsServers` 默认使用系统解析器列表，`hostsFile` 默认使用系统 hosts 文件。`dnsQueryTimeoutMs` 默认 1500，`dnsMaxCnameDepth` 默认 8，`dnsMaxRecords` 默认 256，`hostsMaxBytes` 默认 1 MiB。DNS 使用这些配置的解析器，不擅自选择外部公共解析器；遇到拒绝或无效回答，不会通过询问另一台服务器规避。

规则支持精确主机、域名后缀、线性时间正则和 IP 网段，可附带端口与数据库标识。测试例外必须使用精确主机或 IP。生产完全保护拒绝访问；审计保护只接受执行器能保证只读的操作效果，HTTP GET 本身不构成这种保证。同一 DNS 回答中，一个 IP 的例外不能放行其他可能连接的地址。

一个资源可在 `aliases` 中绑定额外选择器，包括网络端点与本地数据路径。所有选择器共享保护策略和 ID，别名不能自行指定测试或保护级别。每个选择器独立指定端口和数据库范围，不继承另一个选择器的限定。数据库文件标记同时保护 SQLite 风格的 `-wal`、`-shm`、`-journal` 附属文件。所有者必须明确绑定相关数据路径；网络地址不会自动发现这些文件。

受控 HTTP 消费者选用配置的 HTTP(S) 代理时，会在本地解析并通过字面 IP CONNECT 固定目标。规则先于代理连接执行，原始 Host 和 TLS 名称保留。代理必须支持 IP CONNECT 并遵守指定目标。DNS 查询使用配置的本地解析器，不经 HTTP 代理。隧道失败时不回退到直连或未经验证的代理请求。

可选受控网安代理仅在启用的测试服务器选择器精确匹配原始主机且覆盖服务端口时允许解析私有地址，包含所有者明确配置的别名。数据库专属、域名类别、已禁用及其他端口的选择器不授权私有 HTTP 访问。解析出的每个地址及重定向仍接受生产策略检查，完全保护与审计限制优先；私网解析期间规则修订变化时，在建立路由前拒绝请求，包含另一个规则库连接提交的变化。请求、响应和拒绝结果保留在流量记录中。普通匿名 HTTP 抓取继续限制为公网地址。

装配 `./fs` 替换 `fs-sandbox`，保留现有 `sandboxPolicy` 服务。本地 `path` 规则使用绝对服务器目录或数据库文件路径，不能附带网络限定。Windows 规则必须使用带盘符的本地路径，不把远端路径转换成本地路径。完全保护拒绝读取与变更；审计允许结构化读取，拒绝写入和编辑。生产路径优先于重叠的测试路径。符号链接会重新解析，并比较完整精度的文件身份。Windows 通过原生接口枚举硬链接与卷挂载路径，逐项验证身份并复查链接数；结果不完整或元数据变化时拒绝。这能识别生产或所有者目录的外部链接，同时放行无关测试文件的硬链接。其他平台仍拒绝无法归属到受保护目录的外部硬链接。UNC、设备与替代数据流路径需要独立适配器；监听当前也会被拒绝。

受控文件提供方始终保护规则库及 SQLite 辅助文件。`ownerPaths` 增加禁止访问的配置或凭据文件；`readOnlyPaths` 增加可读但不能改写的数据来源。配置的 hosts 文件及国家数据库也禁止改写。所有者通过规则服务配置，与 Agent 文件访问分离。

普通文件删除和不覆盖目标的改名使用同一强制规则，包含改名两端和源文件版本校验。在 `tool-fs` 开启 `fileOperations` 可提供对应可选工具。生产完全保护和只读审计均拒绝这两种操作，完全权限也不能绕过。首次效果前重新检查策略变更；已提交的改名保留规则所有者直至源名称清理结束。清理失败时 `FS_PARTIAL_MUTATION` 明确报告两个名称可能同时保留。不支持目录操作和跨文件系统移动。

装配 `./subprocess` 替换 `subprocess-local`。只要存在大陆保护、生产规则或受保护的所有者/数据文件，就拒绝普通进程和 PTY 分配。测试主机名或完全权限不能约束任意代码。只有内存规则库、关闭大陆保护、没有生产规则及受保护本地来源的组合才能委派原进程提供方；开启本地策略会取消此前准入的进程。该提供方不提供操作系统级目标沙盒。

可选 `./subprocess-native` 在 Windows Node 24 上用已验证的 BaseContainer 后端替代上述仅准入实现。它依赖 `targetProtection`、`credentials`，并要求明确提供 `readonlyPaths`、`readwritePaths`、`temporaryRoot` 和 `network`（`disabled` 或 `gateway`）。授权路径必须存在，可写授权必须是目录；解析别名后，私有根仍须位于所有授权范围之外。该提供方支持普通命令和真实 ConPTY，保留原始/收集/控制流、取消及整个进程范围等待语义；不支持的平台直接拒绝，不委派普通执行。

每条命令使用私有 HOME 与临时目录。环境中的代理变量替换为该次执行的网关；禁用网络时移除代理变量，Host 环境保持不变。可选 `proxy: { protocol, host, port, username?, passwordRef? }` 指定网关上游。密码须与用户名及符合 POSIX 变量名的凭据引用配对；缺少凭据会拒绝激活，每次命令仍会重新解析。代理密码不进入命令环境。已注册的 Agent 作用域提供原生命令与终端的审计归属，通用 Host 进程仍不分配对话。网安上游设置与流量捕获联动仍待完成。

`maxProcesses` 默认 16，执行记录计入容量直至输出结算及清理完成。策略扫描、启动、连接、诊断与清理预算均可通过 [`NativeTargetSubprocess.Config`](src/subprocess-native.ts) 配置。可执行文件查找在读取候选元数据前校验目标策略，规则变化会取消查找；规则提交前先停止保留的执行。无法确认清理时拒绝新任务、保留同步最终终止入口并报告原因。删除私有目录前验证范围。网关模式仍受下述入站及不透明协议限制；默认产品尚未启用此可选实现。

原生终端在同一受限进程范围内启动固定辅助程序。用户参数和环境只在辅助程序启动后经独立继承管道传入，终端字节不能成为控制回复。辅助程序等待有效的 ConPTY 进程 ID 后才确认启动，并缓存早期终端输出。输入、尺寸调整、前台检查和信号均采用有界确认；长输入保留 UTF-16 代理对，输出遵循背压。句柄发布后解除分配阶段的取消关联。默认启动 30 秒、单次操作 5 秒、最多 64 个待确认请求；操作结果未知时停止会话，不自动重放。

私有 Broker 和终端入口会将工作进程执行失败报告到 stderr，并使用退出码 127。终端入口在结束所属辅助进程前刷出控制确认消息。

关闭或 shell 自然退出都会结束整个原生终端范围，包括分离后代，然后才释放保护。正常退出保留已交付的 UTF-8 尾部，显式关闭可丢弃未读取输出。Windows 以 shell PID 表示控制台伪进程组，SIGINT 通过 Ctrl-C 交付；不支持的信号会失败。无法验证提示符状态时只报告未知或忙碌，确认整个范围关闭后才报告空闲。真实 Windows 测试覆盖启动失败、输出暂停和分离后代回收；默认 profile 和界面整合仍需另行完成。

在 `network: gateway` 下，可选 `httpsInspection: true` 检查 CONNECT 内的 HTTP/1.1。它要求 CONNECT 名称、TLS SNI 和 HTTP Host 一致，按当前规则逐次校验请求，并保留上游证书验证。字面 IP 目标可省略 SNI。重定向返回调用者，后续请求重新检查；此模式拒绝嵌套 CONNECT、WebSocket 升级及其他应用协议，不回退不透明转发。默认值为 false。

每次检查执行通过 `NODE_EXTRA_CA_CERTS`、`SSL_CERT_FILE`、`REQUESTS_CA_BUNDLE` 和 `CURL_CA_BUNDLE` 获得临时公开 CA 证书。签名私钥仅存于宿主内存，不修改系统信任或代理设置；应用须支持这些进程级设置。`maxHttpsCertificates` 默认 64，`httpsCertificateLifetimeMs` 默认一天；到期或容量耗尽后拒绝新隧道，需启动新执行。`connectTimeoutMs` 限定准备及握手时间，`requestTimeoutMs` 限定完整检查连接的时间，包括未完成的请求头。关闭时等待转发请求结束后才释放保护。

私有 Broker 还接受供 [Windows WFP 辅助程序](../../../native/target-guard/README.zh.md)使用的内部 `ingress` 配置。它保留第二个独立观察的 Job，等待原生规则安装完成后才放行工作进程；辅助程序失效时停止该范围，独立进程计数归零后才释放规则。独立恢复客户端分别报告已删除、保留和无法识别的记录；进程身份未知或系统启动身份变化时保留规则。公开原生提供方及默认 profile 未启用这条开发路径。提权、受保护安装和高权限网络/恢复成功验收仍未完成；权限不足时拒绝执行，不放宽策略。

新规则库默认关闭大陆保护且不添加目标规则；重新打开时保留已明确保存的偏好。这是可选进阶后端，不进入默认执行路径。装配 `./country` 可使用固定版本的 DB-IP Lite 数据，`path` 默认指向内置文件，`maxBytes` 默认 32 MiB，`maxAgeDays` 默认 45。启用大陆保护后，缺失、损坏、未来或过期数据不能证明目标位于境外；`.cn` 与中文中国域名标签作为独立依据。无法确认的名称或地区按拒绝处理，精确测试例外除外。界面不会将部分后端展示为完整保护。

国家数据是覆盖和精度有限的估计。[IP Geolocation by DB-IP](https://db-ip.com) 按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 分发。使用这些结果的 Web 组合展示署名链接。详见[内置署名](assets/NOTICE.md)。

配置托管 `cacheDirectory` 后，应用所有者可在目标保护面板点击「检查数据更新」。`targetProtectionSettings.updateCountry` 通过 HTTPS 检查 [DB-IP 官方月度归档](https://db-ip.com/db/download/ip-to-country-lite)，遵循 Host 进程代理环境。提供方限制下载和解压大小，校验 Country Lite 格式与编制月份，然后原子写入更新的有效缓存。重启优先读取最近一次校验通过的新缓存。无效、非字节流或较旧的数据不会替换当前数据。显式 `path` 仍由所有者维护。成功更新会刷新首次网安确认，并取消使用旧数据的请求。

用 `./security-proxy` 替换 `security-proxy-local`，并提供必需的凭据和目标保护服务。受控客户端、HTTP 转发及连接检查先校验原始目标，再通过字面 IP CONNECT 连接。转发保留原始 Host 和 TLS 身份，拒绝不匹配的 Host，并逐跳检查重定向。不透明 CONNECT 要求所有者将该字面 IP 和请求端口明确标记为测试服务器，生产规则仍检查目标 IP 与已知别名。隧道关闭前保留规则版本，所有者撤销规则时先关闭隧道，再保存新规则。保留受控普通 HTTP 提供方可让独立代理关闭时继续执行规则。

装配 `./ssh` 替换普通 SSH 连接，要求 `credentials` 与 `targetProtection`，再使用 `fs-ssh`。它采用[显式直连 SSH 配置](../../ssh/ssh/README.zh.md#direct-connection)，校验原始名称和 DNS 别名，固定一个字面目标并验证服务器密钥。服务器完全保护在 TCP 建连前拒绝；审计允许结构化文件读取并拒绝变更。精确的私有测试端点可执行有界文件操作，不放宽匿名 HTTP 限制。文件调用在远端工作区重新解析两种路径表示并拒绝越界链接；完全权限也不能扩大该工作区。

共享 Linux 主机可在该 SSH 绑定上设置 `protectedPaths: [{ path: /srv/production, protection: full }]`。每条规则要求路径为已存在的绝对路径。通过摘要核验的 helper 在连接就绪前安装规则，并在文件读取、目录条目返回、流式分段读取和变更生效时检查路径与文件身份。`audit` 允许读取并拒绝变更。[Linux 挂载坐标](https://www.kernel.org/doc/html/latest/filesystems/proc.html#proc-pid-mountinfo-information-about-mounts)可识别绑定挂载别名。精确文件规则也匹配设备与 inode。无法确认是否指向受保护目录的外部硬链接会被拒绝。开启远端路径保护后，任意进程和转发请求不可用。使用配套的 Linux helper，并由可信管理员管理其挂载命名空间和运行时。独立挂载的网络文件系统和外部进程的并发修改需要另行隔离。

SSH 文件系统效果不会因为端口不同而被视为与其他资源无关。数据库/端口限定冲突，或存在尚无远端身份映射的生产路径规则时，会拒绝操作。任意命令、PTC、终端流和未知协议调用仍属于无法约束的执行，保护开启时拒绝；这不代表测试服务器的完全自由执行已完成。本地策略撤销后连接关闭，不会悄悄重连。SSH 默认直连 TCP。显式配置 `proxy: { protocol, host, port, username?, passwordRef? }` 可经可信 HTTP(S) CONNECT 代理连接，与环境变量和网安模式界面配置独立。代理认证要求用户名与已保存的凭据引用成对提供。原始 SSH 主机名在本地校验，CONNECT 只发送一个已核准的字面 IP，SSH 指纹校验仍为必需。读取代理凭据及建立隧道后均复查规则；拒绝、取消或规则变更绝不回退直连。代理 TLS 使用系统信任库。此路由不提供负载捕获或远端资源映射。

装配 `./rea` 替换普通 REA 根服务，保留现有 `rea/agent` 消费者。提供方在原生启动前校验直接连接，并在分派前校验每个排队的外部调用。拒绝条件与 `./subprocess` 相同，包括受保护的所有者文件；引擎名称和 MCP 只读声明不能证明目标隔离。本地策略变化或所有者撤下会关闭已有进程，等待调用结束后才释放规则资源。该可选适配器拒绝不支持的原生执行，不提供 REA 沙盒，也不保护独立配置的 MCP 客户端。

对每个受控服务器装配 `./mcp` 替换 `mcp-client`，沿用其设置及 `tools` 服务。目标或所有者文件保护存在且无法约束服务器效果时，在连接前拒绝 stdio 和 HTTP MCP。每次重连、发现、工具调用和资源请求均复查执行策略，MCP 只读声明不构成安全效果证明。撤销会关闭 SDK 持有的进程和传输，取消请求并停止重连。无法确认关闭时保留可见错误，规则所有者保持到关闭回执到达。此适配器提供准入与撤销，不是原生引擎沙盒或 HTTP MCP 目标适配器。

装配 `./sqlite`，以 `databases: [{ name, path }]` 绑定已有本地 SQLite 文件。它要求原生 `DatabaseSync.setAuthorizer`，不支持的运行时会激活失败。可选 `./sqlite-agent` 使用 `tools` 和 `sandboxPolicy` 提供 `database_query`，低于完全权限时强制只读。SQL 选择配置名称，不能另选路径。完全保护在分配 helper 前拒绝，审计使用原生只读连接。测试批次支持参数绑定、内置函数和全文检索，并原子提交。附件库、扩展、日志修改及自行控制事务由引擎授权回调拒绝。

默认执行 30 秒、锁等待 1 秒、1000 行、结果 1 MiB、输入 64 KiB、SQLite 堆 64 MiB、终止宽限 1 秒及四个保留请求，关闭尚未确认的辅助进程也计入容量。受管私有 helper 允许终止同步死循环查询，结果保留重复列、二进制、大整数及非有限浮点值。运行时和 helper 必须位于 Agent 不可写位置。本适配器不隔离高权限外部文件替换，也不覆盖其他数据库协议。

提交前复查路径、原生文件身份和规则，并持有规则快照到原生操作结束。其他规则写入者收到 `busy`；WAL 读者不能阻止写入者，因此持有操作会拒绝 WAL 规则库。授权前变更会回滚批次，取消或超时不会发出提交许可，可能需要恢复未提交日志。授权后等待结果和清理；`SQLITE_OUTCOME_UNKNOWN` 要求核验结果，禁止自动重放。

SQLite 同时检查配置路径和真实路径旁的日志。主库必须只有一个硬链接，启动及提交前均检查；多个名称可能对应不同日志（[SQLite 说明](https://sqlite.org/howtocorrupt.html#_multiple_links_to_the_same_file)）。迁移硬链接绑定时，先停止客户端，用 SQLite 一致性备份生成唯一文件，再更新 `databases[].path` 及路径规则。不要改名活动数据库或丢弃恢复日志。已提交后清理失败报告 `SQLITE_COMMITTED_CLEANUP_FAILED`，不得重放；`SQLITE_CLEANUP_FAILED` 表示尚未发出提交许可。

装配 `./postgres`，并提供 `targetProtection` 与 `credentials`，可执行固定的 PostgreSQL 目录审计。通过 `databases: [{ name, hostname, port, database, username, passwordRef, caPem? }]` 绑定端点，端口默认 5432。每次操作解析凭据引用，强制校验证书及原始主机名；私有 CA 可提供 PEM。仅支持原生 PostgreSQL 直连，不支持重新映射数据库的连接池或代理。网络规则不能自动发现服务器数据文件和别名，需另行绑定。

可选 `./postgres-agent` 注册 `database_inspect`，接收配置名称。结果包含核验后的数据库、账号和版本、表名、表种类、行级安全状态及选定安全设置。完全保护在 TCP 和认证前拒绝。审计在只读事务中使用固定的 `pg_catalog` 查询，先核验身份再读目录。PostgreSQL [READ ONLY 不禁止所有磁盘写入](https://www.postgresql.org/docs/current/sql-set-transaction.html)。

对与生产环境隔离的专用测试实例，可在绑定中启用 `testSql: true`。配置精确的测试服务器主机规则，以及匹配该绑定主机、端口和库名的测试数据库规则。同一实例上任何受保护的生产数据库会阻止测试 SQL。服务器所有者负责函数、扩展和网络隔离。执行器在发送测试语句前核对数据库、事务模式及账号权限，拒绝带提升属性或获授其他角色的账号。

当绑定已启用且沙盒策略服务可用时，`./postgres-agent` 提供 `database_test_sql`。执行需要会话完全权限。每次调用在受管事务中执行一条受支持的 PostgreSQL 语句，`$1` 等参数独立传递。执行器管理事务，并在 PostgreSQL 确认提交后返回成功。提交回执丢失时，先核对测试库状态再决定是否重试。默认 SQL 和 JSON 参数各限 64 KiB，可用 `maxSqlBytes` 配置。

对于共享 PostgreSQL 实例，在绑定中配置 `sharedTestTables: [{ schema: fixture, table: items }]`，并添加精确到主机、端口和测试库的规则。`./postgres-agent` 提供 `postgres_test_write` 进行参数化插入、更新或删除。它要求会话完全权限、无高权限属性及角色成员资格的数据库账号，以及操作和加锁所需的表权限。生产库规则仍保护自己的绑定，生产服务器规则则作用于整个端点。更新和删除必须有非空等值条件。匹配超过 `maxRows` 时回滚，服务器确认提交后才返回受影响行数。

共享写入会锁定普通表并复查目录条目。列仅支持内建布尔、整数或文本类型，且不可有默认值、标识列或生成表达式。有触发器、重写规则、行级安全、继承、外键、检查约束、表达式或部分索引的表会被拒绝。写入账号应只获得允许表所需的权限。端点所有者需在事务期间控制模式命名和服务器扩展。该工具只接收数据参数，不接收用户编写的 SQL。

每次 PostgreSQL 操作解析一次 DNS，固定一个已检查字面地址，保留原始 TLS 名称，不重试其他地址。凭据解析后及每条查询前后复查规则；取消、超时或服务撤下会销毁套接字，确认原生关闭后才释放规则。默认限制为 30 秒、每条查询 1000 行、解码结果合计 1 MiB、四个待处理操作。输出限制不约束 PostgreSQL 协议报文的内存分配，只应连接所有者配置的可信服务器。错误采用不含凭据的稳定代码，不自动重放。

装配 `./mysql` 并提供 `targetProtection` 与 `credentials`，再装配 `./mysql-agent` 提供 `mysql_inspect`。绑定需填写 `name`、`hostname`、`database`、`username`、`accountHost` 和 `passwordRef`，端口默认 3306。`accountHost` 对应 `CURRENT_USER()` 返回的账号主机部分，例如 `%`。使用字面 IP 时，需显式提供证书中的 DNS 名 `tlsServerName`。私有证书颁发机构可通过 `caPem` 配置。

执行器在拨号前校验端点和配置的证书名称，固定到一个获准 IP，并用原始 DNS 名或显式配置的名称校验证书。`mysql_inspect` 核对数据库、实际认证账号和 TLS 密码套件，再用固定的只读查询读取该库的表目录。规则变更或取消时，执行器关闭连接后再释放所用的规则修订。

绑定列出 `testTables` 且沙盒策略服务可用时，提供 `mysql_test_write`。写入要求会话完全权限、精确到主机、端口和数据库的测试规则，以及采用直接表授权的 MySQL 8 账号。专用绑定还要求精确的测试服务器规则。给配置的表授予 `SELECT`、`TRIGGER` 与所需的 `INSERT`、`UPDATE` 或 `DELETE`。执行器借助 `TRIGGER` 权限确认目标表没有触发器，并在持有事务的表元数据锁期间检查 InnoDB 引擎和触发器元数据。

提交包含 `operation` 和 `table` 的 JSON 操作。插入、更新还需提供 `values`，更新、删除还需提供非空的 `where` 等值条件。执行器生成预处理语句，并独立绑定参数。`maxRows` 约束语句直接影响的行数，`maxResultBytes` 约束输入和结果。专用实例的外键可能改动关联测试行。实例与其复制链路需和生产隔离。服务器确认提交后才返回成功，回执丢失时应先核对测试库再决定是否重试。

在绑定中设置 `sharedTestWrites: true` 可为共享 MySQL 实例的指定测试表启用写入。账号还需要表级 `UPDATE` 或 `DELETE` 以获取读锁，以及全局 [`PROCESS`](https://dev.mysql.com/doc/refman/8.0/en/information-schema-innodb-foreign-table.html) 来检查入向和出向外键，包括写入账号看不到的引用表。工具使用固定目录查询，拒绝这两种外键关系。账号在工具以外使用 `PROCESS` 时可以查看其他会话活动。请保管凭据并隔离复制链路及服务端扩展，避免测试变更传入生产。系统库不参与共享写入。生产库规则覆盖大小写变体，生产服务器规则仍保护整个端点。

装配 `./browser` 替换 `dsh-browser-use`，保留所选 Playwright MCP、Chrome DevTools MCP 或 Stagehand 提供方。三个提供方均在原生获取前解析必需执行许可，排队调用前复查。撤销后关闭资源，规则保持到原生结束；缺少策略会撤下注册服务及其提供方。拒绝条件与 `./subprocess` 相同。本适配器提供准入和撤销，不提供浏览器逐目标隔离；测试标签不能约束任意浏览器文件、网络或脱离进程的效果。普通无保护组合保留原行为。

用 `./cordis` 替换 `dsh-cordis-host-runner`，在代码运行前拒绝动态 Host 启动、面板启动、Client 源码交付及处理器调用。定义和只读检查仍可用。即使目标规则关闭，此提供方也拒绝执行：Host VM 和页面代码无法在后续规则变化时可靠终止或隔离。完全权限和 Client 审批不能覆盖。可信配置可显式更换提供方，不会自动回退。

用 `./plugin-manager` 替换 `dsh-plugin-manager`，保留本地插件和 bundle 列表；修改配置、版本豁免、安装、删除、registry 检查和包查询要求来自经过身份认证且仍连接的所有者 Remote 调用。所有者设置沿用原方法。模型工具显式清除继承的 Remote 身份，完全权限也不例外；没有所有者调用身份的直接进程内调用会被拒绝。两个适配器都要求 `targetProtection`，所有者服务撤下会使提供方停用，旧引用也拒绝执行。这些是管理准入控制，不能隔离任意可信 Host 插件，也不能阻止所有者主动更换受控组合。

可选 `./ptc` 替换 `dsh-ptc-runtime-node`，每次调用在独立 Node Worker 内创建 QuickJS WebAssembly 解释器。它接入现有 `run_code`，接受可擦除类型的异步 TypeScript 函数体，只暴露声明的异步绑定和控制台输出；不提供 Node、进程、原生文件/网络、计时器或模块加载。解释器分配、堆栈、源码/输出/消息大小、并发调用、Worker 数量和截止时间均有经过验证的配置项。其他组合仍可使用原 Node PTC 提供方。

有副作用的绑定必须使用相应受保护提供方，解释器不能约束任意可信 Host 函数。绑定仍负责自身取消和清理；`run_code` 返回前会取消并等待已启动工具清理。策略撤销会停止 Worker；原生关闭无法确认时抛出 `PTC_SHUTDOWN_UNCONFIRMED`，拒绝该运行时后续调用，并保留规则租约和容量直到实际退出，重新使用前需重启 Host。此可选提供方尚未进入默认产品，不等同于任意命令的目标隔离。

QuickJS 与 [quickjs-emscripten](https://github.com/justjake/quickjs-emscripten) 提供 MIT 许可的解释器和 WebAssembly 桥接；`quickjs-emscripten-core` 与 `@jitl/quickjs-wasmfile-release-sync` 固定为 0.32.0。源码与编译后的 Worker 路径分别验证。

## 实现

<details>
<summary>维护细节</summary>

SQLite 格式使用单调递增的 `SCHEMA_VERSION = 3` 和应用标识 `DSTP`。有效的版本 1、2 规则库通过事务升级，保留偏好与修订号；旧代码重新打开时会拒绝版本 3，因此降级需恢复升级前备份。版本 1 不允许路径，版本 3 之前不允许别名。格式、应用标识和规则在同一个 SQLite 快照中读取，每次操作都重新检查。写入在事务中比较调用方读取的修订号；锁冲突返回 `busy` 且不提交，损坏数据保留。

HTTP 消费者在解析前和每次连接前检查，包括重定向。解析器保留同一回答报文中的 CNAME 与 A/AAAA 记录，校验事务及问题身份，限制名称链深度，并在 UDP 回答截断时改用 TCP。hosts 文件别名和 localhost 无需外部查询。共享传输固定已经校验的地址，并保留 NAT64 的 IPv4 别名用于规则和地区检查；无关回答记录不会成为连接目标。

判定使用最新规则，并在异步解析后复核版本。本地规则变化或国家数据提供方替换会取消使用旧代的请求，但不会回滚已经发出的操作。HTTP 与文件执行器持有规则所有者资源，直至原生操作和清理结束。未绑定字面地址的代理事实仍保持未知。规则库失败、取消和服务释放不会授权连接。

本地文件适配器校验直接服务调用，并在文件锁内、暂存前及原子发布前复查写入。其他规则库连接的变更也可拒绝发布并清理暂存残留。撤下服务时中止准入，等待进行中的 I/O 和源迭代器关闭后再释放依赖。本地文件系统仍有外部进程替换路径的竞态：重新校验路径不等于隔离恶意进程在校验与系统调用之间替换父目录。已创建的部分父目录及此前完成的操作不会回滚。

文件身份采用 BigInt 设备号和 inode，不舍入 Windows 标识。已有文件的身份不可用时，不能判断它与生产文件无关；尚不存在的待创建文件单独处理。DNS 证据按规范化主机名保存，资源的多个别名不会覆盖彼此的绑定；不适用于当前端口或数据库范围的选择器不会触发 DNS 查询。

原生执行可通过 `nativeFileConstraints()` 获取独立的文件限制快照，再由内部原生文件策略构建器编译显式授权。目录扫描覆盖链接目标和完整 Windows 硬链接名称；预算、取消和目录变化均会拒绝不完整的策略。生产只读限制优先于其内部的可写授权。可选原生命令提供方使用这些限制；默认产品接入仍需完成。

私有原生工作进程只在引导身份验证并加入独立 Job 后加载。有界帧协议区分目标标准输出、错误、第 7 号描述符流量、直接退出、流结束和内层范围退出，输出字节不能成为生命周期消息。目标接收显式请求环境。工作进程复用严格 Windows Job runner 管理命令范围，直接退出后仍保留存活后代；内层范围及其流关闭后，引导自然退出，宿主仍须确认外层 Job 归零才能释放保护。受理消息只表示启动管道可用，不证明目标已经执行。传输或观察失败会终止工作并保留失败状态。源码和编译路径已通过可选 `Subprocess` 提供方验证；完整协议覆盖与默认产品接入仍未完成。

内部宿主句柄在调用 MXC SDK 前，先于严格外层 Job 中启动固定可信 Broker。因此即使 SDK 尚未返回句柄，取消也能覆盖它已创建的后代。准备阶段先分配私有网关，再解析完整的目标环境；Broker 使用单独清理过的环境。启动采用调用方配置的截止时间；目标流复用有界收集和溢出文件，有界 Broker 诊断独立保留。规则与代理必须等独立外层范围关闭后释放；结果未知时保留保护并报告失败。已在 Windows Node 24 验证编译后的宿主/Broker/工作进程完整链路，并用于可选 `./subprocess-native` 提供方；默认产品仍需接入。

内部原生网关为一个保留的规则修订绑定回环监听。HTTP 保留方法与正文、校验 Host、同时解析名称及别名，并固定每次准入的地址。私网目标必须由所有者明确标记为名称或 IP 精确匹配的测试服务器。重定向交回调用方，下一次请求重新校验。CONNECT 同时检查原始名称和字面地址，不声称能验证应用域名或数据库身份；域名、正则或数据库规则存在歧义时拒绝不透明流量。可选上游失败不回退直连；关闭时先等待套接字结束，再释放规则修订。

Windows 源码和编译链已验证测试访问成功、生产零连接，以及绕过网关直接出站返回 `EACCES`。可选 HTTP/1.1 TLS 检查另行校验名称与明文请求。MXC 1.0.1 的无身份代理要求 `ingress.default=allow`，这不等于完整入站隔离。其他应用协议、严格入站对端隔离和默认产品装配仍未完成。

`retainNativeExecution(revision, stop)` 保持已核准的规则修订，直到调用方确认其进程范围和网络传输均已关闭。并行命令可共享保留的修订；所有者配置变更先停止全部已准入原生执行，再提交新规则。无法确认停止时保持禁止准入，并保留旧修订。所有者显式重试会再次检查关闭，不会重放命令。国家数据源变更也会撤销原生执行。释放回调代表物理关闭确认，不能当作无条件清理回调。

规则库和本机准入日志使用独立的 SQLite 文件。Session 投影保留相同的脱敏记录和来源身份。TypeScript 与 Python SDK 保留这些事件，不将其合并到助手回复。

</details>

<a id="model-experience"></a>
## 模型体验

根服务不增加模型请求。可选 `./sqlite-agent` 增加 `database_query`，`./postgres-agent` 增加 `database_inspect` 和按需启用的 `database_test_sql`，`./mysql-agent` 增加 `mysql_inspect`。结果和带类型拒绝进入正常工具日志。其他适配器改变相应工具结果。效果由执行器提供，不能由模型宣称安全。

#### KV 缓存影响

只有可选数据库工具会增加提示词参数定义，不调用辅助模型。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

仅覆盖明确装配的受控提供方。结构化文件删除和改名支持本地文件及匹配的 SSH helper。其他数据库协议、远端数据库资源映射、受限命令的默认装配以及浏览器/MCP/REA 原生执行仍未完成。部署方必须确保远端运行时可信，且位于 Agent 可写工作区之外。受控网安代理仅接受明确标记的测试 IP 不透明隧道。这类隧道记录元数据，无法验证应用名称或数据库身份。可选原生网关可检查 TLS 内的 HTTP/1.1。网安模式界面路由与 SSH 负载捕获仍需独立实现。普通匿名抓取仍拒绝私有网络。DNS 证据不能枚举共享某个 IP 的所有主机名，国家数据或 CONNECT 也不能证明实际转发位置。已绑定网安代理以外的审计归属仍未完成。
