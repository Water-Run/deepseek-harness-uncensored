# @deepseek-ai/dsh-target-protection

[English](README.md) | 中文

## 概述

这个可选后端保存生产和测试目标，并能在目标收到请求前拒绝 HTTP 连接。生产限制优先于测试例外；规则库失效或目标证据缺失不会变成默认放行。默认产品尚未启用此集成：地区分类、其他执行适配器和管理界面仍在开发。

<a id="use-this-package"></a>
## 使用本包

装配根服务时，通过 `path` 明确指定独立的 SQLite 规则库。与 Web 服务一起装配 `./http`，替换普通 HTTP 抓取提供方。两者使用同一个 ID，不能同时装配。受控消费者必须依赖 `targetProtection`；移除该服务会撤下消费者，而不会恢复无保护抓取。

`busyTimeoutMs` 限制 SQLite 锁等待（默认 1000）；`checkTimeoutMs` 限制地址检查（默认 5000）；`maxRechecks` 限制并发配置变化后的复查次数（默认 3）。这些选项不授权重放网络操作。

规则支持精确主机、域名后缀、线性时间正则和 IP 网段，可附带端口与数据库标识。测试例外必须使用精确主机或 IP。生产完全保护拒绝访问；审计保护只接受执行器能保证只读的操作效果，HTTP GET 本身不构成这种保证。同一 DNS 回答中，一个 IP 的例外不能放行其他可能连接的地址。

规则库默认开启大陆保护。地区分类尚未接入，因此未知地区会被拒绝，除非命中精确测试例外。若域名或正则生产规则可能适用，无法核实的名称解析链也会被拒绝。界面不会把这个部分后端展示为完整保护。

<a id="implementation"></a>
## 实现

<details>
<summary>维护细节</summary>

SQLite 格式使用单调递增的 `SCHEMA_VERSION = 1` 和应用标识 `DSTP`。仅空数据库可初始化，其他应用数据库和未来版本会被拒绝，损坏数据保留供诊断。写入在事务中比较调用方读取的版本；读取可看到其他连接已提交的最新状态。

HTTP 消费者在解析前和每次连接前检查，包括重定向。精确保护主机名会解析为地址别名；共享 HTTP 提供方把连接固定到已经检查的地址。判定使用最新规则，并在异步解析后复核规则版本。代理解析的实际地址明确保持未知。规则库失败、取消和服务释放不会授权连接。

独立规则库不改变 Session 记录类型。持久化执行审计事件及 SDK 投影属于后续审计接入。归档开发草稿不是受支持的数据库前代，不会自动导入。

</details>

<a id="model-experience"></a>
## 模型体验

本包不增加模型请求或工具定义。现有抓取调用可能返回带类型的目标保护错误。操作效果由执行适配器提供，不能由模型宣称命令安全。

#### KV 缓存影响

不增加提示词前缀。拒绝只改变对应的工具结果。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

当前仅覆盖明确装配的受控 HTTP 提供方。它不是进程沙盒，尚未执行 shell、PTY、SSH、文件系统、数据库协议、浏览器、MCP/REA 或独立网安代理的保护。地区数据和完整 DNS 名称链校验尚未接入，未知证据按拒绝处理。生产只读审计需要结构化执行适配器。默认产品装配、所有者界面、首次网安确认状态和持久化审计仍未完成，这些需求继续保留。

<a id="dev-note"></a>
## 开发备注

测试包含真实本机监听器、SQLite 跨连接冲突、重新打开与损坏检查，以及真实 Loader 配置下必需提供方的撤下。正则使用 RE2JS，IP 网段规范化使用 ipaddr.js。实施计划与剩余验收记录在 [目标保护计划](../../../.agents/requirements/2026-10-26-target-protection.md)。
