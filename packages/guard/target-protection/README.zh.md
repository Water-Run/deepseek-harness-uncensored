# @deepseek-ai/dsh-target-protection

[English](README.md) | 中文

## 概述

这个可选后端保护 HTTP 和本地文件操作中的生产目标。它将 DNS 绑定到连接地址，支持本地国家数据，并在审计规则下允许结构化文件读取。生产限制优先于测试例外；无法约束操作范围的任意进程会被拒绝。默认产品尚未启用此集成，其他适配器和管理界面仍未完成。

## 使用本包

装配根服务时，通过 `path` 明确指定独立的 SQLite 规则库。与 Web 服务一起装配 `./http`，替换普通 HTTP 抓取提供方。两者使用同一个 ID，不能同时装配。受控消费者必须依赖 `targetProtection`；移除该服务会撤下消费者，而不会恢复无保护抓取。

`busyTimeoutMs` 限制 SQLite 锁等待（默认 1000）；`checkTimeoutMs` 限制地址检查（默认 5000）；`maxRechecks` 限制并发配置变化后的复查次数（默认 3）。这些选项不授权重放网络操作。

`dnsServers` 默认使用系统解析器列表，`hostsFile` 默认使用系统 hosts 文件。`dnsQueryTimeoutMs` 默认 1500，`dnsMaxCnameDepth` 默认 8，`dnsMaxRecords` 默认 256，`hostsMaxBytes` 默认 1 MiB。DNS 使用这些配置的解析器，不擅自选择外部公共解析器；遇到拒绝或无效回答，不会通过询问另一台服务器规避。

规则支持精确主机、域名后缀、线性时间正则和 IP 网段，可附带端口与数据库标识。测试例外必须使用精确主机或 IP。生产完全保护拒绝访问；审计保护只接受执行器能保证只读的操作效果，HTTP GET 本身不构成这种保证。同一 DNS 回答中，一个 IP 的例外不能放行其他可能连接的地址。

装配 `./fs` 替换 `fs-sandbox`，保留现有 `sandboxPolicy` 服务。本地 `path` 规则使用绝对服务器目录或数据库文件路径，不能附带网络限定。完全保护拒绝读取与变更；审计允许结构化读取，拒绝写入和编辑。生产路径优先于重叠的测试路径。符号链接会重新解析，直接硬链接会比较文件身份；保护目录外无法归属的硬链接会被拒绝。UNC、设备与替代数据流路径需要独立适配器；监听当前也会被拒绝。

受控文件提供方始终保护规则库及 SQLite 辅助文件。`ownerPaths` 增加禁止访问的配置或凭据文件；`readOnlyPaths` 增加可读但不能改写的数据来源。配置的 hosts 文件及国家数据库也禁止改写。所有者通过规则服务配置，与 Agent 文件访问分离。

装配 `./subprocess` 替换 `subprocess-local`。只要存在大陆保护、生产规则或受保护的所有者/数据文件，就拒绝普通进程和 PTY 分配。测试主机名或完全权限不能约束任意代码。只有内存规则库、关闭大陆保护、没有生产规则及受保护本地来源的组合才能委派原进程提供方；开启本地策略会取消此前准入的进程。该提供方不提供操作系统级目标沙盒。

规则库默认开启大陆保护。装配 `./country` 可使用固定版本的 DB-IP Lite 数据，`path` 默认指向内置文件，`maxBytes` 默认 32 MiB，`maxAgeDays` 默认 45。缺失、损坏、未来或过期数据不能证明目标位于境外；`.cn` 与中文中国域名标签作为独立依据。无法确认的名称或地区按拒绝处理，精确测试例外除外。界面不会将部分后端展示为完整保护。

国家数据是覆盖和精度有限的估计。[IP Geolocation by DB-IP](https://db-ip.com) 按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 分发，详见[内置署名](assets/NOTICE.md)。使用这些结果的 Web 组合必须展示该署名链接。当前更新数据需要替换配置的本地来源并重载提供方，产品设置接入尚未完成。

<a id="implementation"></a>
## 实现

<details>
<summary>维护细节</summary>

SQLite 格式使用单调递增的 `SCHEMA_VERSION = 2` 和应用标识 `DSTP`。打开有效的版本 1 规则库会事务升级，保留偏好与修订号；旧代码拒绝版本 2，因此降级需恢复升级前备份。仅空数据库可初始化，其他应用数据库和未来版本会被拒绝，损坏数据保留供诊断。写入在事务中比较调用方读取的版本；读取可看到其他连接已提交的最新状态。

HTTP 消费者在解析前和每次连接前检查，包括重定向。解析器保留同一回答报文中的 CNAME 与 A/AAAA 记录，校验事务及问题身份，限制名称链深度，并在 UDP 回答截断时改用 TCP。hosts 文件别名和 localhost 无需外部查询。共享传输固定已经校验的地址，并保留 NAT64 的 IPv4 别名用于规则和地区检查；无关回答记录不会成为连接目标。

判定使用最新规则，并在异步解析后复核版本。本地规则变化或国家数据提供方替换会取消使用旧代的请求，但不会回滚已经发出的操作。HTTP 与文件执行器持有规则所有者资源，直至原生操作和清理结束。代理解析的实际地址明确保持未知。规则库失败、取消和服务释放不会授权连接。

本地文件适配器校验直接服务调用，并在文件锁内、暂存前及原子发布前复查写入。其他规则库连接的变更也可拒绝发布并清理暂存残留。撤下服务时中止准入，等待进行中的 I/O 和源迭代器关闭后再释放依赖。本地文件系统仍有外部进程替换路径的竞态：重新校验路径不等于隔离恶意进程在校验与系统调用之间替换父目录。已创建的部分父目录及此前完成的操作不会回滚。

独立规则库不改变 Session 记录类型。持久化执行审计事件及 SDK 投影属于后续审计接入。归档开发草稿不是受支持的数据库前代，不会自动导入。

</details>

<a id="model-experience"></a>
## 模型体验

本包不增加模型请求或工具定义。现有抓取、文件和进程调用可能返回带类型的目标保护错误。操作效果由执行适配器提供，不能由模型宣称命令安全。

#### KV 缓存影响

不增加提示词前缀。拒绝只改变对应的工具结果。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

仅覆盖明确装配的受控 HTTP、本地文件和进程提供方。文件系统服务没有删除、重命名方法，这两类操作随任意进程执行被阻止，尚无结构化操作支持。SSH、数据库协议、浏览器、MCP/REA 原生进程与独立网安代理仍需适配。未知代理目标会被拒绝，代理端地址绑定仍未完成。DNS 证据描述配置解析器的回答，不能枚举共享某个 IP 的所有主机名；国家数据也不能证明物理位置或归属。默认产品装配、所有者界面、首次网安确认状态和持久化审计仍未完成。
