# 额度限制

内置的人民币请求准入与滚动统计。通过 `llm/stream` 和 `web/deepseek-search-request` 覆盖模型请求及原生搜索，不改变模型输入。界面说明见[根 README](../../../README.md)。

`path` 指定本机 SQLite 账本；`pollMs` 控制跨进程等待检查间隔；`rates` 声明每个 provider/model 的人民币输入、缓存、输出价格、上下文上限和搜索费用。默认采用 2026-10-23 公布的 Flash 高峰价格，搜索每次预估 0.005 元。费用估算包含缓存读写，不重复累加推理 token。

SQLite 事务保证不同进程无法同时花费同一额度。发送前持久预留，完整成功响应按用量结算；缺少完整用量、取消或异常退出按预留计入。活跃预留不会随窗口过期；死进程的遗留预留从恢复时开始计时。损坏账本、未知费率或无法提交预留会阻止新的受限请求。关闭先撤销入口、取消等待，再等待在途请求结算并释放数据库。

sessionUsage 仅允许应用所有者读取对话中已记录的回答与重试用量。它按当前配置费率估算人民币费用，与限额是否开启无关，排除继承事件并标出无法计价的请求；曲线最多 240 点，总额不受抽样影响。辅助调用不计入此估算。

## 恢复与升级

恢复只记录真正因额度等待、且由正常会话提供方持有的 AgentLoop 请求。预测、标题、已获准的请求和其他运行环境不会被误记为待恢复对话。用户取消会清除等待，应用关闭保留实际等待；Web/桌面控制器按原模式、目录与旁问配置恢复，并继续持有 Agent 的释放句柄。

暂停记录带稳定身份与独占领取信息，持久化确认接续前不删除；失败释放领取，死进程的领取可重新接管。继续通知记录暂停标识，重试检查已排队或已记录的通知，避免重复投递。服务关闭先取消并等待恢复调用，再关闭账本。`configure`、`resume`、`reset` 的 Remote 调用仅允许应用所有者；这不将拥有本机文件访问权的进程隔离成沙箱。

账本自动从 v1/v2 升级到 `SCHEMA_VERSION = 3`，保留费用、活跃预留、自动恢复和金额配置。原总开关开启时迁移为六档全部开启，关闭时全部关闭；新账本默认全部关闭。`enabledPeriods` 是唯一的窗口开关来源，停用的窗口不参与准入或恢复判定。旧暂停记录缺少可信分类时仍保持待确认，只能由明确的恢复操作解除。

`reset(period)` 只排除该窗口已经结算的记录，其他窗口及在途请求不变；之后完成的请求仍计入。省略参数则重置全部已结算统计。停用窗口不会删除历史，重新启用时继续使用保留的记录。升级前退出使用同一账本的旧进程；旧构建不能读取 v3，不支持降级或手工修改 `user_version`。Session 日志的冻结代际未改动。

## Known Limitations and Deferred Work

这是本应用的保守费用估算，不是服务商账单。默认按整个上下文容量预留，可能提前等待；可降低模型最大输出或调整限额。所有窗口均关闭期间的请求、其他付费工具和应用外请求不计入。自定义模型或接口必须配置匹配费率；远程共享文件系统不受支持。用户可明确重置已完成统计，活跃请求仍保留预留。
