# SSH 会话连接与独立代理路由

状态：新增可选入口、消费方及定向验收已完成，并随 `2026.11.17.1` 检查版交付。两平台实际包内入口成功导入，Windows 已保留数据安装；实体远程行为及完整剩余范围继续见 [TODO](../TODO.md)和[本版交付](2026-11-17.1-delivery.md)。

## 交付范围

`target-protection/ssh-sessions` 在原有受保护 SSH 连接上提供确切 Agent 归属。无 Agent 的 Host 元数据连接单独初始化，不继承触发提供方加载的会话。每个存活 Agent 的连接分别持有规则修订；网安模式且独立代理开启时，经该会话保留的上游进行字面 IP CONNECT，同时核验 SSH 主机密钥与 helper 摘要。代理失败不回退直连。

`ssh/execution` 的 `resolveSshExecution` 统一选择连接，原有固定提供方保持兼容。文件流在分配、后续拉取与关闭中保持原连接；普通进程、终端的启动、控制、输出和终止也不随调用者切换连接。已有操作不迁移、不重放；确认关闭后，新操作才可重新选择路由。

Agent 释放、模式变化和相关代理变化会撤下连接。尤其是“代理关闭时已建立直连，随后开启代理”和“普通模式改为网安模式”都必须撤下旧直连，不能继续复用。未受代理覆盖的普通模式连接不因独立代理配置变化而中断。`maxSessions` 默认 16；清理未确认的连接仍占容量并保留依赖。

CONNECT 建立及拒绝以 `ssh` 归属到对应会话，记录的只是隧道元数据，不含解密后的 SSH 负载或加密字节统计。该功能只路由 SSH 传输，不能据此声称远端命令的后续外连已使用本地代理。远端网络执行保护、身份和挂载映射、入站及其他协议继续待交付；进阶保护与代理默认值不变。

## 验证

三项资源归属用例在候选实现中通过；临时恢复旧文件及子进程消费方后，文件流读取、终端写入和普通进程启动三项均失败。随后逐字节恢复候选文件并核对 SHA-256。该负对照验证真实调用路径会因重新选择连接而失败，没有修改校验器或断言条件。

新增用例还覆盖两个网安会话并发、交叉调用者中的原始审计归属、Agent 释放、容量限制、代理变更、代理拒绝不回退、普通模式直连、关闭后开启代理、模式切换、Agent 触发的部署初始化、等待 CONNECT 时释放，以及执行保留晚到时不建立 TCP。最后两项通过可控屏障而非固定睡眠安排时序。

路由选择抛错时，必须在创建审计等待前失败。将判定临时移回旧顺序的负对照，先出现多余监听器计数的断言失败，随后夹具关闭超时；候选逐字节恢复后通过。此失败说明无归属的等待会保留规则所有者，不能仅以未建立 TCP 判断清理完成。实现已将路由判定移到审计等待创建之前。

会话用例经 YAML/Loader 加载实际提供方，使用私有回环 SSH/CONNECT 监听器、真实 Agent/Session 注册及实际独立代理实现；远端文件请求由自建协议夹具响应。所属测试保留流量列表元数据的稳定快照，过滤时间和网络地址，不改写 Session 录制。消费方资源归属用例使用受控 helper 回包与本机流。没有连接用户或生产服务器，也未把这些证据当作实体远程设备验收。原有 POSIX helper、文件、进程和沙盒回归继续纳入 Linux 检查。

Windows 两个独立进程并发，各 8 个文件、67 项通过；Linux 共 21 个文件、190 项通过。新增会话与消费方场景共 15 项。打包清单的 177 项回归通过，包含缺少选择器 bundle、共享 chunk 或保护入口时拒绝的检查。8 项产物构建、2 项聚合编译、全仓 lint、398 个 NodeNext 声明 API、389 包 publint、导出 JSDoc 和五组文档配对通过；普通 Node 从声明依赖的工作区导入实际构建入口，默认会话容量核对为 16。

材料位于 `%USERPROFILE%/DSHU-Deliveries/20261116/`，前缀 `ssh-sessions-`。`consumers-negative.log` 为三项负对照，`negative-restore.log` 为候选恢复核对，`bound-resources.log` 为新增场景，`linux.log` 为 Linux 扩大回归，`concurrent-{1,2}.log` 为独立进程并发。构建、聚合编译、lint、打包入口和双语校验结果在最终检查回执中保留。
