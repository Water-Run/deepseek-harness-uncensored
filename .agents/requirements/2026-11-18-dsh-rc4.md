# DSH 0.2.2-rc.4 适配

上游于北京时间 2026 年 11 月 18 日 01:53 发布 `dsh-v0.2.2-rc.4`，提交为 `3f321d32bfe382212a8ed8785c1d47a5a300aa23`。当前源码已接入并随 [Windows 18.2](2026-11-18.2-delivery.md)保留数据安装；内部 18.1 检查包仍使用 rc.3，Linux rc.4 新包尚未完成。REA 最新发布仍为 6.9.0，不改其来源与工具数量。本项属于原有内核跟进和稳定性验收，不替代其他需求。

## 改动

官方 rc.3 → rc.4 差异主要是包版本、DeepSeek Messages 拒答结算和 LiveShare Worker。适配保留 DSHU 的 GPL 声明、日期产品版本、四模式提示词、模型目录设置、REA 和可选保护；同步 15 个仅本分支拥有的 Harness 包版本。桌面包的日期版本基线保持不变。

Messages 流在拒答前消耗的 token 会先发出用量，再返回 `CONTENT_REFUSED`；拒答解释保留。请求没有新增 `safety_check`，提供方拒答仍如实报告。兼容说明沿用上游的 [rc.3 升级指南](../../docs/upgrade-guide/v0.2.2-rc.3/deepseek-refusal-code/guide.zh.md)。LiveShare Worker 继承 Host 的 Electron Node 模式，避免错误地作为 GUI 启动。

## 验证状态

71 项提供方和 LiveShare 定向用例通过；完整构建十项、后续两项聚合类型检查、包元数据和升级指南校验通过。hygiene 首次 24 项通过，另有一项因维护文档链接升级至 rc.4 而触发精确模板校验；同步该模板后单独复验通过，没有重跑其余已通过检查。69 个持久化根类型仍匹配既有 21 条历史记录，无 Session 格式迁移。

新增拒答 Session 的逐条记录在 Windows 回放中匹配。原始 POSIX JSONL 保持不变，场景明确标为 POSIX；另外建立采用现有 PowerShell 组合的独立作者场景及其请求头基线，保留 DSHU 的实际提示词。只读回放通过，核对完整 Session 与请求头，其他 219 项未运行；没有修改正常化器或旧基线。原始 POSIX 场景仍待 Linux 验收。证据为同日 `dsh-rc4-refusal-replay-accepted.log`。

Windows 实际产物、完整实装清单、CLI、非空导出、正式插件升级注册及正常启动已验收。Fedora 转发间歇中断，Linux rc.4 实体机验收仍未完成。没有创建或发布 Release。

## 上游 rc.5 对照（2026-11-19）

DSH 官方预发布 `0.2.2-rc.5` 固定源码为 `9c2670d3bce5275e0d1610272958121af87787bb`。上游基础组合移除了固定的 `searchProvider`，由 Web 服务按当前模型提供方选择服务器端搜索或 DeepSeek Search API。以 rc.4 内容为对照，对 DSHU `c34e3cd965` 预演移植时，有 5 个冲突文件，分别是根目录和 Desktop 的 `package.json`、Web README 的双语正文和配对记录。[官方发行](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.5)

当前源码、安装与 Fedora 待传源码包仍以 rc.4 为内核。上游升级说明确认，新默认路由可能把自定义网关的默认 Key 送往官方 Messages 搜索端点。DSHU 源码已补齐同源检查。未单独设置搜索端点的自定义 DeepSeek API Key 对话沿用网关和对应密钥引用。显式跨源复用同一引用时，在读取密钥和发出请求前停止。独立搜索密钥仍可用于明确配置的端点。[上游搜索迁移说明](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.2-rc.5/docs/upgrade-guide/v0.2.2-rc.4/web-search-deepseek-model-default/guide.md)

搜索和抓取提供方的 12 个定向测试文件共 373 项通过，覆盖网关继承、跨端口拒绝和独立密钥。Windows 的 `web-search-endpoint-guidance` 历史回放多出平台技能提示，搜索错误文本一致。rc.5 移植后仍需验证普通配置的自动路由、显式覆盖、凭据缺失和保护配置。[凭据迁移](../../docs/upgrade-guide/v0.2.2-rc.4/messages-search-credential-origin/guide.zh.md)

可选 Web 保护配置已停用内置 Messages 搜索和 DeepSeek 搜索与抓取 API，保留逐跳检查的本机 `http`。本机实际 CLI 输出和组合测试均记录三项原始提供方被禁用且受控 HTTP 已装配。组合和 HTTP 共 12 项定向测试通过。独立的 `headless` 网页抓取历史回放在 Windows 多记录了一条系统技能提示。该回放加载自己的固定抓取提供方，未加载本次保护配置。[配置迁移](../../docs/upgrade-guide/v0.2.2-rc.4/target-protection-web-providers/guide.zh.md)
