# SSH 中央资源与远端文件保护

状态：真实执行链路和定向回归已实现，并随 17.3 分发；当前 17.5 Windows 实装和 Linux 归档均包含中央文件映射。实际包内核对与恢复入口见[当前交付](2026-11-17.5-delivery.md)。本项推进 09.04–09.08 的远端文件执行保护，服务器、数据库和完整审计的剩余范围见末节。

## 当前行为

可选 `target-protection/ssh` 和 `ssh-sessions` 接受 `pathMappings: [{ ruleId, remotePath }]`。管理员明确关联中央资源 UUID 与远端绝对路径；本地路径和远端路径不会按名称隐式对应。中央资源须包含路径选择器或路径别名，启用的生产资源提供 `full` 或 `audit` 等级。停用和测试资源不增加远端限制；缺失、非路径和无效引用拒绝启动。静态规则与映射规则合计最多 128 条。

连接先保留中央规则修订，再校验目标、SSH 主机密钥及 helper 摘要。经过认证的 helper 解析实际路径并确认安装规则后，才允许结构化文件操作。完整保护拒绝读取和写入，只读审计允许读取、拒绝写入；无关测试目录仍可写。补丁、删除和移动使用相同保护，移动在产生效果前检查源与目标。

准入只认可当前连接确认安装的资源。未映射生产路径、主机、端口及数据库限制仍然生效；普通连接检查不会获得映射豁免。取消或规则修订变化使旧准入失效。修改规则先等待 helper 确认关闭，再提交；重新建立的连接读取新等级。保护开启时，任意远端命令、PTC、终端及未知请求仍拒绝。

进阶保护默认关闭，没有改变普通模式和默认配置。配置与限制的权威说明见[保护包 README](../../packages/guard/target-protection/README.zh.md)。未增加 Session 事件或更改持久化字段。
