# 可选目标审计升级说明

仅影响显式配置 `targetProtection.auditPath` 的 Host。默认启动不启用目标保护和本机审计。

1. 更新前退出使用同一 HOME 的所有 Host，再备份 `auditPath` 指向的审计库和会话数据。保留备份，不向运行中的 SQLite 文件直接覆盖数据。
2. 新实现自动将审计库版本从 1 升至 2，保留历史行、稳定 ID 与指纹密钥。旧记录没有会话来源，界面显示“未记录关联对话”。规则库路径和版本不变。
3. 发起 Agent 的进程内操作在检查开始时捕获 Session，准入记录保留发起 ID 与元数据中已有的父会话 ID。对应会话新增 `target/admission`，模型历史和正常助手回复不变。
4. 在“设置 → 模式 → 网安 → 准入审计”展开新条目，核对发起对话；来源 ID 可搜索。独立代理已发放的监听器将 HTTP/CONNECT 请求关联到准确的存活会话，Host 探测明确不分配会话。已注册 Agent 的原生命令/ConPTY 网关及继承真实发起 Agent 的 PTC Worker 回调保留准确归属，并共享网安上游与流量捕获；关闭审计仍有效。没有执行 Agent 的通用调用和其他 Worker 不据来源 ID 推测代理权限。
5. 旧审计实现会拒绝版本 2。需要降级时，保留新数据归档并使用升级前的备份。旧 Session 读取器会在回放前拒绝新的必需事件，含 `target/admission` 的会话继续由新运行时读取，不能通过删除事件来降级。

Session 格式保持 4，冻结的 JSONL 代际未改写。[持久化确认](../persistence/changes/2026-11-05-target-admission.md)记录兼容判定和验收。审计库和 Session 追加失败会停止新的放行效果；修复存储问题后重启 Host。
