# 网安流量查看与导出

状态：实现已随 [Windows 18.2](2026-11-18.2-delivery.md)完成打包、实包运行和保留数据安装验证。未创建或修改 Release。此项归入 `10.03`，其余原始需求保持不变。

## 行为

设置读取、流量列表和详情各自维护请求代际，旧回复和旧失败不能覆盖当前结果。关闭详情使其待返回回复失效；清理成功后，旧列表、详情和捕获计数不能恢复。有效列表刷新计数，列表失败保留设置，清理失败保留记录。

「导出 JSON」保存符合当前筛选的全部留存详情，不受界面列表上限影响。输出沿用存储时的脱敏、正文截断与 CONNECT 隧道说明，不回显搜索原文。提供方按完整 UTF-8 JSON 加末尾换行核验字节上限，超限返回具名错误，不返回部分文档。仅应用所有者可导出。格式与配置见[提供方说明](../../packages/guard/security-proxy-local/README.zh.md#use-this-package)。

切换 Host 会清空旧连接的设置、记录、筛选、密码与未保存代理草稿。旧写入回执不能污染新 Host 的状态，也不会阻止其保存；关闭控制器会等待各连接已启动的写入及已接受的文件保存完成。清理、换连接或退出后，尚未接受的导出回复不能启动下载。

已有 Remote 方法、已保存设置、Session 格式和模型输入保持原行为；新增导出方法及可选配置不需要数据迁移。此次导出文件不支持导入。
