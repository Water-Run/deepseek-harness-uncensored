### 配置兼容说明

四个预设内的记忆消费行由 `memory` 更名为 `memory-agent`，避免与宿主记忆服务的行 ID 重复。默认用户无需操作，根 `memory` 服务设置与已保存记忆保持原位置。若自行编写了匹配预设内部 `id: memory` 的补丁，请将该选择器改为 `id: memory-agent`；根服务的选择器不要改。运行 `pnpm run verify-cordis-config` 核对配置。按本分支公开文档仅保留 README 的要求，迁移说明保存在本内部验收记录。
