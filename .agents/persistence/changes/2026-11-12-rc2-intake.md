## Compatibility

The writer remains Session format 4. Existing ordinary messages and catalog versions 0 through 2 remain readable. Retry sources annotate empty UserMessages without changing model-history derivation; older readers preserve extensible source metadata and may show an empty context row. Historical settlement notices need no stopReason, and historical tasks need no ownerName; absent values are not inferred or backfilled. New catalog version 3 and the required team/mode event are rejected by older readers before they can restore an incorrect child or Team selection. The existing event discriminators therefore prevent unsafe interpretation without a format bump. DSHU's input/prediction and memory/extraction payloads retain their existing fields and inherit the source-metadata additions. This is the combined fork acknowledgement, separate from retained upstream reference declarations. No committed Session generation or accepted predecessor record is rewritten; downgrade requires a pre-upgrade data backup when an older reader cannot admit new records.
