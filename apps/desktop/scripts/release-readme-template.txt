 ═══╡ 02 ╞════════════════════════════════════════════════════════════════════

   首次运行  /  FIRST LAUNCH

   安装包未做代码签名，首次打开时系统可能拦截：

   ► Windows   SmartScreen 提示时，点「更多信息」→「仍要运行」
   ► macOS     右键点击应用 →「打开」；或在终端执行：

     $ xattr -dr com.apple.quarantine \
         "/Applications/DeepSeek Harness Uncensored.app"


 ═══╡ 03 ╞════════════════════════════════════════════════════════════════════

   校验下载  /  VERIFY

   ► Linux / macOS
     $ sha256sum -c SHA256SUMS.txt

   ► Windows (PowerShell)，输出与 SHA256SUMS.txt 对照
     > Get-FileHash -Algorithm SHA256 .\DSHU-{{VERSION}}-win-x64.exe


 ═══╡ 04 ╞════════════════════════════════════════════════════════════════════

   卸载与数据  /  UNINSTALL & DATA

   ► deb       $ sudo apt remove deepseek-harness-uncensored
   ► rpm       $ sudo dnf remove deepseek-harness-uncensored
   ► Windows   「设置 → 应用」中卸载
   ► macOS     把应用拖进废纸篓

   会话、设置与凭据保存在：

     ~/.dsh-uncensored                 (Linux / macOS)
     %USERPROFILE%\.dsh-uncensored     (Windows)

   卸载不会删除这些数据；需要彻底清除时，手动删除该目录。
