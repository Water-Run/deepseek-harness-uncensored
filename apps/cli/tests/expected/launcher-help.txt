Usage: dsh-uncensored [--profile] <name> [options] [app-args...]
       dsh-uncensored plugin --profile <name> <pnpm-args...>

dsh-uncensored: boot a DeepSeek Harness profile — an ordered stack of
plugin-bundle patch layers under your own overrides.

Arguments:
  args                           arguments for the booted profile's app (see:
                                 dsh-uncensored --profile <name> --help)

Options:
  -V, --version                  output the version number
  --profile <name>               the profile under $DSH_HOME/profiles to boot
  --from-default-profile <name>  replace a custom profile with a fresh copy of a
                                 shipped profile template
  --patch <path>                 extra patch-list overlay applied after the
                                 profile layer (repeatable)
  --dump-config                  print the composed profile tree and exit
  --dump-config-schema           print JSON Schema for profile entries and
                                 patches without mounting
  --dump-default-config          print the profile tree without its user layer
                                 or --patch overlays and exit

Examples:
  dsh-uncensored web                                   boot the web profile (same as: dsh-uncensored --profile web)
  dsh-uncensored rescue --from-default-profile web
                                            recreate rescue from the shipped web template, then boot it
  dsh-uncensored headless "run the tests"              answer one task, print the result, and exit
  dsh-uncensored tui --patch ./extra.yml               boot a custom profile with one extra overlay
  dsh-uncensored tui --resume <session>                arguments after the launcher flags reach the app
  dsh-uncensored web --help                            the web app's own flags and help
  dsh-uncensored plugin --profile tui add <package>    install a plugin into the tui profile
